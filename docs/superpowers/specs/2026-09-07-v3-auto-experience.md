# V3 自動化のプレイ体験改善

2026-09-07。2026-09-06の実プレイレビューに対応する。従来の[ソロ自動モード](2026-09-05-v3-solo-auto-mode.md)の通常行動・時計・保存契約を維持し、以下の操作と判断を更新する。

## プレイヤーの目的と成果

探索は「新しい集落を見つける」を既定とし、初めて市場圏へ入ったら停止する。出発時点の市場、既に記録した市場、以前の自動実行で発見した市場は既知として扱う。「周辺を調査して出発地へ帰る」では最大歩数の半分を調査区間に使い、出発座標へ通常の一歩ずつ帰る。帰路も遭遇・時間・歩数の上限を守り、帰れなければ未完了として停止する。「歩数を決めて探索する」も残す。探索で未知の遠隔人物や市場在庫を先読みしない。

取得物数、経験、撃破、会話、新しい市場名、実行中の銀貨増減、実現交易利益、商会損益、重要な出来事を操作状態へ記録する。移動ログに埋もれない直近12件の重要記録を保持し、フィールドの反復移動ログに代えて成果と次の行動を表示する。停止後の手動売買や商会設立費は、終了した自動処理の収支へ混ぜない。積荷は現在の台帳を表示し、現金・実現利益と区別する。

次の行動は既存の実装状態から、二市場の記録→売却実績・利益・設立資金→商会設立→営業資格→責任者→販路・支店へ案内する。受諾中の軍務があれば軍務確認へつなぐ。新しい国家キャリアや終局を実装した扱いにはしない。

## 閲覧と行動の境界

地図、国家選択、年代スライダー、台帳の閲覧は自動実行を止めない。地図に同じ実行状態と一時停止・再開・設定変更を表示し、世界観測開始時には地図を開く。表示更新時も台帳入力とスクロールを保持する。

通常の移動、売買、相場記録、回復、軍務、組織操作などの状態確定は共通commit境界で一時停止し、確定後にも停止状態を保持する。手動の月送りは処理を予約する前に停止する。設定、非表示、離脱では引き続き停止する。敵・軍務遭遇が生じた場合は閲覧画面を閉じて現地の選択を見せる。

## 関係する世界変化

既定は現在地、移動先、交易二市場、商会販路の国、および選択した注目国家に関係する新しい戦争・外部危機で停止する。地方の現支配者を参照する。世界全体で停止する設定も選べる。停止時は国または地方名、危機名と危機度、通行・供給・価格への影響を示す。遠方の出来事は件数にまとめ、世界の年代記で確認できる。既に活動中の戦争・危機による反復停止はしない。月次の確定・巻き戻し境界は従来どおり。

## 交易の判断

市場、商品、個数、往復回数、仕入上限、売却下限、手元資金、総予算を基本設定へまとめる。実際に記録した市場相場へ売価も保持し、記録年月付きの仕入総額と価格不変の場合の差益を表示する。売価がない従来の相場記録では不明と表示し、買値から売価を推測しない。未訪問の現在価格は読まない。予測は保証せず、現地で毎個の価格・在庫・荷受余力を再確認する。

停止中の「条件を変更して再開」は実行起点、歩数、往復、段階、仕入数・売却数、使用済み予算、積荷、成果を保持する。行動・探索目的・市場・商品は同じ計画内で変更できず、新しい実行を明示して作る。総予算を使用済み額未満に下げない。設定保存だけなら停止を維持する。

価格停止では市場を開く、進捗を保って条件変更、残荷を持ち帰る、表示した現在価格で一個だけ売る、を選べる。一個売却は販売市場、今回の未売却数、現地価格を再確認し、通常売却・市場在庫・成果記録へ接続する。持帰りは追加仕入れず仕入市場で完了し、積荷を保存する。歩数上限で交易や移動を目的達成済みとは表示しない。

## 個人戦の方針

同じ戦闘計算で次の与ダメージ、反撃、行動後HPを算出し、手動の個人戦にも表示する。自動攻撃は主人公以下のレベルという条件に加え、反撃後HPが停止割合以下になるなら攻撃前に止める。

「体力を優先」「回復品を温存」「積荷を守る」を選べる。温存では指定個数を残し、積荷保護では荷物を持った戦闘を手動判断へ戻す。初めての種類の敵で停止する設定を持ち、既知の敵種を保存する。停止から回復品一個使用と現場の遭遇判断へ進める。敗北・退避後の停止、集団戦の手動判断は維持する。

## 保存・検証

保存全体V6・各ドメイン版を維持し、任意のfield.autoMode操作情報へ加算する。新しい実行では成果を初期化し、発見済み市場・既知の敵種は引き継ぐ。現行保存に新しい任意情報がない場合は空で復元する。非対応の旧世代セーブは従来どおり拒否する。
