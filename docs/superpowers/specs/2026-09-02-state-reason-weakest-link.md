# 国家理性・最弱環ルール実装仕様

> 2026-09-08改訂: 以下の選択規則は厳密比較モード（strict）。V3標準は[確率的国家判断と開発者システム](../../v3-simulation-variables.md)を参照。五条件の投影・効果・承認制約は共通。

## 定義

国家理性とは、国家を存続させるために、その時点で最も弱い存続条件を優先して補強する原理である。

> 国家は、実行可能な行動のうち、実行後の食料・結束・財政・防衛・主権の最低値が最も高くなる行動を選ぶ。同値なら低コスト、なお同値なら国民性で決める。

この一文を厳密比較モードのルールとし、領土拡張、王朝維持、統治者個人の生存を国家存続と同一視しない。国家は世界の真実を全知せず、その月に利用可能な地理、国力、関係、戦争、文化、統治者の情報から実行可能な候補だけを作る。

## 国家生成

全生成国家は `stateReasonPrincipleId: "weakest-link-v1"` を持つ。国家情勢の初期化時に次の五条件を0〜100で生成し、最低値の条件IDを `initialImperativeId` として固定保存する。

- 食料 `food`: 食料安全度 `foodSecurity`
- 結束 `cohesion`: 国内結束 `cohesion`
- 財政 `treasury`: 国家備蓄 `reserves`
- 防衛 `defense`: 軍事即応 `readiness`
- 主権 `sovereignty`: 外部へ国家意思を通せる余地 `sovereignty`

現在の最低条件は `weakestConditionId`、その値は `value` とする。初期国家課題は後から最低条件が変わっても書き換えない。

## 月次選択（strict）

1. 戦争、提案、国境、脅威などから実行可能な候補を作る。
2. 各候補の実行後五条件を、同じ月に確定している自然回復・維持負担・危機圧力も含めて投影し、その最低値を求める。
3. 最低値が最大の候補を選ぶ。
4. 同値なら五条件に生じる減少の合計が小さい候補を選ぶ。
5. なお同値なら現在の種族・地方構成・国家文化・統治者との適合が高い候補を選ぶ。
6. なお同値なら候補ID順で決定し、同じ世界と年月の再現性を保つ。

厳密比較モードではsoftmaxによる抽選はせず、選択候補を確率1、他を0として記録する。V3標準のweightedモードは実際のsoftmax抽選値を記録する。プレイヤー支配国の開戦・停戦は従来どおり承認待ちにし、待機中に実行する守備・戦線維持も同じ五条件へ反映する。

投影値と実適用値は同じ月次差分を使う。平時の財政・食料回復には国力由来の上限を置き、上限を越えた結束・財政・食料・防衛・主権は維持負担で緩やかに低下する。国境緊張は主権を低下させる。この月次差分を候補比較から除外してはならない。

## 危機と戦争の成立

平和行動だけで五条件が恒久的に100へ張り付かないよう、通商は財政を改善しても主権を直接増やさず、緊張緩和と停戦は主権上の譲歩を伴う。同盟は相互提案・受諾と二国上限を維持し、安全保障上の主権を改善できる。

共有国境があり、国境透過性20以上、国力比1.1以上、強国側の攻勢意図25以上で、両国の食料・財政・主権が45以上なら、同盟・戦争・休戦中を除いて構造的な国境競争が生じる。競争中は月次で関係を1悪化、緊張を2上昇させるが、通常の緊張自然減1と交易・外交・相互後退の効果を同時に受ける。どちらかの国家存続条件が45未満なら追加圧力を停止し、崩壊状態を機械的に深掘りしない。

主権・食料・財政の圧力を受け、国力比1.05以上の国家は近隣威圧を候補にできる。威圧は関係悪化、緊張、攻勢意図を蓄積するが、緊張84以上かつ危機3か月以上では同じ威圧を反復できない。限定戦争は、共有国境の危機が緊張84以上、関係15以下、危機3か月以上、休戦なし、防衛62以上、攻勢意図45以上の時だけ候補になる。開戦月は既に支払った動員費と翌月以降の戦線維持費を二重計上せず、継戦中に財政・食料・結束・防衛を消耗させる。これにより威圧、動員、開戦、戦線維持、疲弊、停戦を一つの因果鎖として扱う。

## 保存と表示

- 国家情勢形式はv2とし、v1は既存の食料・結束・備蓄・即応を保持したまま主権と国家理性を補完する。
- 各月の国家イベントへ選択後の最低値、残る最弱条件、各候補の最低値とコストを保存する。
- Generation V3の世界地図・国家詳細へ、五条件、初期国家課題、現在の最弱環、ルール本文を表示する。
