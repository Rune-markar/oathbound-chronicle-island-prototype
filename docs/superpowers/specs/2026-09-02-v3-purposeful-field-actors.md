# Generation V3 目的駆動型フィールド人物・敵生成仕様

## 目的

詳細マップの人物・敵を「歩いた先で確率的に湧く駒」ではなく、概算世界で先に起きている国家、集落、生態、天体の処理をプレイヤーが局所的に観測した存在として扱う。画面密度を下げるだけでなく、なぜそこにいるのかをデータと台詞で説明できることを必須にする。

## 生成順序

1. 世界シード、世界年月、フィールド日付、国家状態を入力に、その日の `ActorPlan` を世界単位で決定論的に作る。
2. 行商、集落任務、地方の生息敵、隊商襲撃者、新月の霊体の順に候補を作り、同じ詳細座標へ重ならないよう確定する。
3. 通常の13×11視界を描く時は、計画座標が可視範囲へ入った人物だけを投影する。遠隔地の詳細マスを毎月走査しない。
4. 日付、国家シミュレーション、昼夜の天体作用が変わった時に計画を再計算する。会話・撃破済み座標は従来のV3差分で除外する。

## 行商の因果

- 実在する街道の両端集落について、概算区画の食料収量と農業・漁港機能から供給力、人口と集落段階から需要を求める。
- 到着国の国家AIが直近に `secure_food`（食料確保）を決定した、または `foodSecurity` が62未満で、かつ供給差があれば、国境越えは「国家の食料輸入」、国内は「国家の食料補給」とする。国家決定が起点の場合は `nationalActionId` を保持し、理由文にも明記する。
- 到着国が戦争中で供給力があれば「戦時の糧秣輸送」とする。平時でも需要差が十分大きく重要街道なら「集落間の食料流通」とする。
- 同じ到着国へは一日一隊までとし、選ばれた街道の一地点だけを、その日のプレイヤーが観測し得る行商段階として配置する。
- 行商人は品目、出発集落、到着集落、街道、目的と理由を保持する。会話文はこのデータから作り、無目的な定型文を出さない。

## 集落人物と敵の因果

- 各集落は一日一名を上限に、通常時は都市機能を支える働き手、戦時・城塞・国境・迷宮では集落と街道を守る巡回役を計画する。
- 野外敵は一地方一体を上限に、地方内の通行可能かつ集落外の概算区画から、生息地タグに適合する種を選ぶ。敵は縄張り、狩り、水場での待ち伏せ、営巣など種別の目的を持つ。
- 街道盗賊は先に行商計画が存在し、到着国の結束が低いか戦争中である場合だけ、対象隊商を指定して生成する。
- 新月の霊体は新月の夜かつ遺跡のある区画だけに、その遺跡へ引かれた顕現として生成する。
- アイテムは人物の意思を持たないため、低確率3.5%の座標配置を別系統として維持する。

## 上限と保存境界

- 基本上限は「到着国ごとに行商一隊、集落ごとに任務人物一名、地方ごとに生息敵一体」。因果が成立した場合だけ隊商盗賊と遺跡霊体を加える。
- `ActorPlan` は世界状態から再構成できる派生情報であり、V3セーブへ全人物一覧を追加しない。既存の `interactedTiles`、`defeatedTiles`、`collectedTiles` を継続利用する。
- 敵のレベル、個人戦、会話、購入、NPCの種族・気質生成は従来契約を維持する。

## 受け入れ条件

- 同じ入力では人物ID、目的、座標が一致し、座標が重複しない。
- 食料余剰国から食料安全度35の不足国へつながる街道では「国家の食料輸入」が一隊生成され、出発・到着・品目・街道が追跡できる。
- 全人物・敵が `actorId` と `purpose.kind`、`purpose.label` を持つ。
- 人物・敵の総数が詳細マス総数の1%未満となる小世界回帰を持つ。
- 従来どおり敵発見で一歩手前に止まり、個人戦へ移行できる。新月霊体は昼に残らない。
- 1280×720と390×844の通常V3画面で新地形、正方形マス、移動、横溢れなし、console warning/errorなしを確認する。
