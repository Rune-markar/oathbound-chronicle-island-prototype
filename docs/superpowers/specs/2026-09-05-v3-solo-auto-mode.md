# V3 ソロプレイ自動モード

2026-09-07更新：探索目的・成果・関係地域停止・閲覧継続・交易条件の途中変更・戦闘方針は[プレイ体験改善仕様](2026-09-07-v3-auto-experience.md)を現行正本とする。以下は2026-09-05の初回実装記録。

## 目的と入口

ソロプレイの繰り返し操作を任せる。既定の `index.html` に常設する「自動モード」で、行動と大まかな方針を選び、「オプション・細かい設定」を必要なときだけ開く。

- 行動: 周辺を探索、目的地へ移動、交易巡回、世界を観測。
- 慎重: 敵と人物で停止、HP60%停止、80%以下で所持回復品使用、街道優先。
- 標準: 敵で停止、人物と会話、HP40%停止、70%以下で回復、街道優先。
- 積極的: 同レベル以下の敵を攻撃、人物と会話、HP30%停止、60%以下で回復、距離優先。同レベルでも敗北はある。
- 各プリセットは詳細値をまとめて設定する。変更後は各詳細値を個別に調整可能。

## 実行規則

1. HP、遭遇、軍務引渡し、商会事故、犯罪組織の報告・事後判断、実行上限を確認する。
2. 次の一手を選び、手動と同じドメイン行動を実行する。
3. `ActionResult` を `commitV3Action` へ渡し、共通時計・月次・市場在庫・横断イベントを一度だけ確定する。
4. 進捗と直近20件の記録を保存し、次の一手を予約する。

実行中は現在の行動、停止理由、歩数、経過ゲーム時間、銀貨増減、観測月数、一時停止・再開・終了を表示する。900/450/225msの表示間隔で1/2/4倍を切り替え、行動や月次は省略しない。最大30000行動、探索履歴256座標、経路探索24000展開で処理を有界にする。

## 各行動

### 探索・移動

探索は可視の隣接マスだけを候補にし、訪問回数が少ない順に進む。同じ近傍の往復が4回に達したら停止。移動は生成世界の集落または受諾済み軍務の作戦地点へ、横ラップと通行可否を守って1マスずつ歩く。地形を使う有界A*で街道または距離を優先し、経路は実行中だけキャッシュする。最短・最安全の保証はしない。未知の人物・敵・在庫を経路選択に使わない。最大歩数1〜10000、最大時間1〜720時間を指定する。

### 交易巡回

相場を記録した異なる二市場を選ぶ。仕入市場へ歩く→現地で1個ずつ仕入れる→販売市場へ歩く→今回買った個数まで1個ずつ売る→仕入市場へ戻る、を1〜20往復する。

商品、個数、仕入上限価格、売却下限価格、手元に残す銀貨、全巡回を通じた仕入総予算を指定する。在庫・積載・価格・資金を毎回再確認し、条件外では停止する。遠隔価格を先読みせず、手動売買と同じ世界在庫を更新する。途中の手動操作後は現在の積荷と現地条件を再確認する。銀貨増減は売買以外の報酬・損耗も含む個人資金差であり、利益の保証ではない。

### 世界観測

1〜120か月を、1か月ずつ共通時計で進める。世界情勢に加えて商会・犯罪組織も進む。新しい戦争・外部危機で停止するオプションは全モード共通で既定ON。既に活動中の戦争・危機だけでは停止しない。月次は最小の確定単位であり、発生月の処理を巻き戻さない。

## 中断・保存

- 手動入力、設定画面、非表示、ページ離脱で停止する。再開は明示操作。
- 敵からの自動退避は最大2試行。成功後も進路確認のため停止し、同じ敵へ無人で再突入を繰り返さない。
- 設定は現行V6の `field.autoMode` に任意の操作設定として保存する。既存の世界・ドメイン版や保存全体版は変更しない。現行V6で設定がない場合は既定の待機設定を使う。旧版・未来版セーブの拒否は維持する。
- 実行状態は設定、進捗、交易段階、上限の起点、停止理由、履歴を含む。再読込時はrunningをpausedへ戻し、経路・タイマーを復元しない。
- 「設定を保存」「この設定で開始」は新しい実行計画を作る。「再開」は現在の計画の進捗・予算消費を引き継ぐ。
- 保存失敗では自動実行を停止する。設定は端末内のみで、複数端末同期とオフライン経過の追算は行わない。
- 軍務の受諾、集団戦の準備・指揮、組織の作戦発令・報告判断、商会設立・採用は手動。
