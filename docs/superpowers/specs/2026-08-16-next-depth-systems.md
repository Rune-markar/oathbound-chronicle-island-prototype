# 生活・人物・所領・戦役の深化仕様

## 目的

Elona系作品の「小さな資産、重量、期限、仲間個人の事情、失敗しても続く生活」と、信長の野望系作品の「利害の異なる家中・領民、兵站、複数軍団、攻城、限定講和」を、誓界記の生成世界と一人の人物史へ接続する。数字だけを増やす補助台帳ではなく、現在地、人物、所領、外国地方という実在対象を選ぶ通常プレイループにする。

## 1. 家・倉庫・個人商店・積載管理

- 生成集落へ実際に入ったときだけ、町屋、貸倉庫、店舗兼住宅を取得できる。
- 交易積荷は個数上限と商品別重量の両方を満たす。鉄など重い商品は少数でも荷車を圧迫する。
- 倉庫は物件所在地と生成地方に拘束され、遠隔操作できない。商品、数量、取得原価を保存する。
- 店は店舗兼住宅でだけ開店できる。倉庫から在庫を移し、価格倍率を決め、地域相場・人口・月から決定的に月次販売する。
- 家賃・維持費を払えなければ滞納し、三か月で閉店する。ゲームは終了せず、財産と年代記を残して再建できる。

## 2. 同行者の個人クエスト

- 現在のパーティーにいる実在同行者ごとに、旅、届け物、実戦の候補を生成する。
- 依頼は本人、対象地方／相手、期限、達成条件、忠誠・士気・恐怖への予告を持つ。
- プレイヤーは承諾、保留、拒否を選ぶ。拒否や期限切れは関係悪化を生むが年代記を終わらせない。
- 旅は実際の地方到着、届け物は対象積荷の消費、実戦は実際の戦闘結果を証拠として完了する。
- 結果は個人クエスト履歴と人物年代記へ残し、同行者の忠誠、士気、恐怖、離脱危険、後任適性に影響する。

## 3. 所領政治

- 同じ生成所領事業に領民、名望家、商人、家臣が別の負担・利益・要求を提示する。
- 事業開始前に討議を必須とし、妥協、領民支持、名望家支持、商人支持、強行を選ぶ。
- 選択は予算、担当者、工期、事故率、反対派、四派支持を確定する。強行は即時の反乱圧力と事件を生む。
- 月次完成時に生成地域の治安、人口、食料、商業、忠誠、反乱圧力へ実値を返し、個人と世界の年代記へ記録する。

## 4. 生成世界の戦役

- 君主だけが、自国と隣接する実在外国地方を対象に戦役を起こせる。戦争目的は限定割譲、通商路確保、辺境救援に限定する。
- 実在同盟国だけを友軍として招く。二つの戦線と軍団ごとの兵力・補給・指揮官・行軍線を保存する。
- 段階は軍議、動員、行軍、攻城判断、攻城、講和または再建。攻城では強襲、封鎖、交渉、撤退を選べる。
- 敗北・補給切れ・撤退はゲーム終了にせず、再建段階と損耗・支持低下を保存する。
- 講和は停戦、通商成果、限定割譲を扱う。生成地方の支配移管は不可逆判断としてUI確認を必須にする。
- 月次AIは戦役提案まで行うが、プレイヤー国家の宣戦・停戦・領土移管を自動確定しない。

## 共通要件

- 旧保存は各領域の `normalize*State` で補完し、同じ世界シード・年月・状態から同じ結果を得る。
- 対象IDと現在地・管轄・役職を実行時に再検証し、呼び出し側が別地方を偽装できないようにする。
- 失敗は原則として回復可能な負債、関係悪化、損耗、再建へ変換し、人物史を継続する。
- 人物の判断は人物年代記、社会へ露出する重大結果は世界年代記へ記録する。
- 1366×768と横向き844×390で通常UIから操作でき、長い内容は人物詳細内をスクロールする。

## 非目標

婚姻、家系図、相続争いは実装しない。単純な後継者指定と同一世界の世代継承だけを維持する。残る未実装と受入条件は `UNIMPLEMENTED_FEATURES.md` を正本にする。
