# 国家理性・最弱環ルール 実装確認

## 実装結果

Generation V3の全生成国家へ、食料・結束・財政・防衛・主権の五条件と初期国家課題を追加した。月次国家行動は確率抽選ではなく、実行後の五条件の最低値を最大化する決定的選択へ変更した。同値時は低コスト、次に国民性・統治者適合で決める。

旧国家情勢v1は破棄せず、既存四条件を維持して主権と国家理性を補完する。既存の同盟相互同意、停戦相互同意、プレイヤー承認、戦争・地方支配との接続は維持する。

## 検証記録

- 焦点回帰: `tests/geopolitical-world.test.mjs` と `tests/nation-generation.test.mjs`
- 確認項目: 国家生成、五条件、初期課題、最弱値最大化、コスト・国民性の同値処理、v1移行、月次再現性、同盟、停戦、承認待ち、36か月長期進行
- V3画面: 世界地図の国家詳細に五条件、初期国家課題、現在の最弱環、最弱環ルールを表示

`npm run check` は775件すべて成功した。実ブラウザでは新規開始、50年事前史生成、世界地図、国家詳細、1か月進行を1280×720と390×844で確認し、両幅で横方向のはみ出しなし、コンソールエラー・警告なし、進行後の五条件・最弱環・候補比較更新を確認した。
