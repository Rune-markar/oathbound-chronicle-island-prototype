# 国家理性・紛争多様化レビュー

## 目的

Generation V3の50年事前史が、国家条件の全面飽和と平和だけへ収束する問題を修正し、同じ国家理性ルールから平時、危機、戦争、停戦が決定論的に分岐することを確認する。

## 原因

行動候補は行動そのものの差分だけで比較していたが、実適用時には食料回復、財政回復、防衛低下が追加されていた。このため表示された「行動後の最弱値」と実際の翌月状態が一致しなかった。また通商、外交、同盟、停戦の多くが主権を増やし、財政には無条件の月次回復があったため、50年で五条件と関係が100近傍へ収束した。危機が生じても同じ威圧を反復して主権だけを補強でき、開戦条件へ移らない場合があった。

## 修正

- 国力由来の平時上限と戦時負担を月次差分として一度だけ計算し、全候補の投影と実適用へ同じ差分を渡した。
- 通商は主権を直接増やさず、外交・停戦は主権上の譲歩、威圧・動員は主権と攻勢意図の回復として再配分した。同盟受諾は相互提案と二国上限を維持する。
- 共有国境、透過性、国力差、強国側の攻勢意図、両国の存続余力から構造的国境競争を決めた。外交と交易はこの圧力を相殺でき、食料・財政・主権のいずれかが45未満なら追加圧力を止める。
- 成熟危機では威圧の反復を止め、緊張、関係、危機期間、防衛、攻勢意図を満たした時だけ限定戦争を候補にする。開戦月は動員・戦線維持コストを二重計上せず、翌月以降の継戦で消耗する。

## 自動検証

- `tests/geopolitical-world.test.mjs`: 月次差分を含む候補比較、投影五条件と実適用五条件の一致、外交・同盟・停戦・承認待ちを確認する。
- `tests/generated-world-war-system.test.mjs`: 持続危機からAI対AI戦争が実国境で始まり、戦争コアへ渡ることを確認する。
- `tests/v3-world-simulation.test.mjs`: 固定シードの50年事前史に完了戦争があり、全国家条件が90以上へ飽和しないことを確認する。

## 長期史サンプル

48×32、4国家、600か月を5シードで比較した。`v3-race-history-600`は完了戦争14件、`conflict-history-600-a`は3件、残る3シードは0件で、全シードが必ず戦争になる強制規則にはしていない。完了戦争はいずれも停戦へ到達し、現在進行中戦争は0件だった。終了時五条件の全シード最低値は45〜54で、旧挙動の全条件97〜100への収束は解消した。

## 実画面確認

Generation V3の既定入口 `index.html` で固定シード `review-browser-600` を新規生成した。既定192×120、7国家から独立勢力を含む8勢力となり、世界地図の年代記に誓暦268年5月の侵攻と同年8月の停戦が表示された。選択国家の五条件は食料59、結束63、財政100、防衛48、主権48で、全面飽和していない。

1280×720と390×844でbodyと世界地図の横幅が各viewport幅に一致し、横溢れ0だった。縦画面で可視だった世界地図ボタン17個はすべて44×44px以上、戦争レイヤーへの切替後も操作でき、console warning/errorは0件だった。ブラウザとlocalhostサーバーは確認後に終了した。Node.js 22.23.2で`npm run remote:check`に成功し、`npm run check`はソース95ファイルと全775テストに成功した。

## 境界

この変更は戦争を必ず発生させるものではない。地理、国力差、攻勢意図、外交選択によって50年間平和な世界も残る。Gitへのコミット・main統合と公開環境への反映は別工程であり、pushまたはデプロイを行った場合だけ別途記録する。
