# 種族変容型・確率的意思決定システム実装仕様

更新日: 2026-08-24
対象: Generation V3の生成世界、国家AI、人物生成、世界地図、V3保存

## 1. 正本と目的

種族特性は固定人格ではなく、世界生成時の初期条件として扱う。現在の社会傾向は、種族基礎値、4気質の実人口、経験、歴史アジェンダから導出する。人物と国家はそこへ個人差、役職、国家文化、現況を加え、候補行動を確率的に選ぶ。

実装の正本は次の通り。

- 種族定義中心値: `src/race-list.js`
- 気質人口、経験、人物・国家プロファイル、評価器: `src/race-decision-system.js`
- 国家行動タグと確率選択: `src/geopolitical-world.js`
- V3世界更新・年代スナップショット: `src/v3-world-simulation.js`
- V3表示: `src/v3-app.js`、`v3.css`
- V3保存: `src/v3-save-system.js`

## 2. 6つの恒常軸

全軸は整数`-100..100`へ丸める。

| ID | 表示 | -100 | +100 |
|---|---|---|---|
| `militarism` | 武断性 | 協調 | 武力・強制 |
| `authority` | 権威性 | 平等・合議 | 階級・服従 |
| `centralization` | 集権性 | 分権 | 集権 |
| `openness` | 開放性 | 排他 | 開放 |
| `ambition` | 野心 | 現状維持 | 拡大志向 |
| `pragmatism` | 現実性 | 信念・感情 | 実利・妥協 |

全60実種族は所属する15大分類の中心値を継承する。エルフ、ドワーフ、ゴブリン、リザードマン、オーク、巨人は実種族固有の中心値で上書きする。エルフの中心値は`(-10, 10, 0, -5, -5, -10)`とする。

世界実基礎値は軸ごとに決定論的な`-10..+10`を加える。同じシードでは同じ値になり、別シードでは変わる。補正は最大15まで受け取れるAPIとするが、通常生成は10を使う。これは中心値だけの揺らぎであり、気質構成や歴史変化とは分離する。

## 3. 4気質と実人口

| ID | 表示 | 主要補正 | 戦争死亡リスク |
|---|---|---|---:|
| `militant` | 強硬型 | 武断性、権威性、野心が高い | 1.90 |
| `submissive` | 服従型 | 武断性・野心が低く、権威性・現実性が高い | 0.46 |
| `cooperative` | 協調型 | 武断性・権威性が低く、開放性・現実性が高い | 0.72 |
| `independent` | 自立型 | 権威性・集権性が低く、野心が高い | 1.08 |

`RaceState.temperamentPopulation`は比率ではなく実人口を保持する。保存・更新時に負数を除き、必ず`RaceState.population`へ正規化する。表示用比率はその都度導出する。

初期値は原則25%ずつとし、エルフだけは強硬20%、服従25%、協調35%、自立20%を標準にする。その後、種族実基礎値とシード由来の小幅差を加え、各気質が8%未満にならないようにして再正規化する。

代表気質は最大人口の気質である。代表値の計算には代表気質だけを使わず、4気質すべてを人口比で加重する。

```text
種族代表値[軸]
  = 種族実基礎値[軸]
  + Σ(気質補正[気質][軸] × 気質人口比)
  + Σ(歴史アジェンダ補正[軸] × 強度)
```

## 4. 人口選択、遷移、経験

### 4.1 戦争人口選択

戦争損失は気質別人口比と死亡リスクで配分する。

```text
気質別損失
  = 総損失 × 気質人口比 × 気質死亡リスク
    / Σ(全気質の人口比 × 死亡リスク)
```

不正値や世界全体の瞬間消滅を防ぐため、単一入力で減らせるのは当該種族人口の35%までとする。これは死亡の上限であり、気質遷移の上限とは別である。

### 4.2 気質遷移

イベント強度は`0..100`で受け取り、各遷移率へ乗算する。一つの遷移元から一度に移せる人口は最大8%。通常の月次入力は小さく、数年から数十年で傾向が見える速度にする。

- 迫害: 協調→強硬、協調→服従、自立→強硬
- 戦勝: 協調・服従→強硬
- 敗戦: 強硬→服従・協調
- 平和: 強硬・服従→協調
- 長期支配: 自立・協調→服従、低率で服従→強硬
- 交流: 強硬・服従→協調
- 繁栄: 強硬・服従→協調

占領政策が治安掃討、または抵抗72以上なら迫害経験も加える。12か月以上続けば「迫害の記憶」、24か月以上の異種族支配なら「長期支配」を歴史アジェンダへ残す。

### 4.3 社会経験

保持する経験は`war`、`domination`、`persecution`、`prosperity`、`contact`の5種で、値域は`0..100`。月ごとに`0.992`倍して減衰する。現在経験は速く薄れる一方、歴史アジェンダは月0.01だけ減衰し、強度5未満にはしない。

平和状態が続く種族には低強度の平和遷移を毎月加える。交易関係が一定以上なら交流、食料・備蓄が高ければ繁栄を加える。種族人口は種族定義の出生傾向、繁栄経験から小幅な自然増減を行う。

## 5. 歴史アジェンダ

歴史アジェンダは気質人口と別に保存する。各項目はID、名称、種別、成立・最終強化年月、対象種族、強度、6軸補正、関係補正を持つ。同じIDの経験が続く場合は重複追加せず強度を補強する。最大24件。

対象種族への関係補正は外交候補の「関係」状況値へ入る。負の記憶は交易・外交・同盟・停戦を不利にし、動員・威圧・戦争を相対的に有利にする。ただし固定禁止にはせず、利益や危険が十分なら別の選択も残す。

## 6. 人物生成と世代交代

人物生成は現在の気質人口比から一つの気質を抽選する。その後、軸ごとに二つの一様乱数の差から個人差`-16..+16`を作る。気質抽選と個人差は世界シードと人物IDから決定論的に再現する。

```text
人物値
  = 種族実基礎値
  + 所属気質補正
  + 個人差
  + 歴史アジェンダ補正
  + 役職補正
```

役職は市民、統治者、指揮官、外交官、地方指導者を定義する。商会の番頭・仕入役は外交官、隊商頭は地方指導者、護衛頭は指揮官として生成する。候補の種族、気質、6軸、個人差は採用後も保存する。

国家統治者は18〜32年のシード決定的な在任上限を持つ。交代時はその時点の種族構成から後継者を生成するため、次世代の統治者分布も歴史変化を受ける。少数派気質が抽選される可能性は常に残す。

## 7. 国家プロファイルと国家形成

国家プロファイルは、種族代表値、国家文化、統治者の気質・個人差、統治者役職補正を合成する。国家文化は既存の政体、統治能力、交易、動員、地方自治、沿岸性から導出する。

国家形成時には権威性と集権性から次を選ぶ。

| 権威性 | 集権性 | 基本形 |
|---|---|---|
| 高 | 高 | 中央集権王政・帝政 |
| 高 | 低 | 封建王政 |
| 低 | 高 | 中央集権共和国 |
| 低 | 低 | 自治連邦・開放都市同盟 |

武断性42以上、権威性12以上、集権性8以上なら中央軍政を優先する。大国かつ野心12以上なら帝政候補になる。従来の文化固有政体は、同じ国家形態と両立するとき表示・制度差として残す。50年史中に周縁地方が独立する場合も、親国家の固定政体を複製せず、成立時点の種族・国家6軸から新政体と元首称号を生成する。

## 8. 選択肢評価と確率化

現在の国家AIが持つ14行動すべてに6軸タグ`-1..1`を付ける。対象は国内再建、食料確保、交易、外交、同盟、国境要塞化、動員、緊張緩和、威圧、限定戦、戦争継続、停戦提案・受諾である。

```text
人格適合度 = Σ(国家値[軸] × 選択肢タグ[軸]) / 6

評価値
  = 既存の戦略効用
  + 人格適合度 × 0.42
  + 利益
  - 危険
  + 脅威影響
  + 関係影響
  + 小乱数
```

小乱数は選択肢評価器で`-2..+2`、既存戦略式側で`-1..+1`に制限する。同じ世界、年月、主体、選択肢なら同じ値になる。

確率はsoftmaxで求める。

```text
P(i) = exp((評価値[i] - 最大評価値) / 温度)
       / Σ exp((評価値[j] - 最大評価値) / 温度)
```

国家AIの温度は17、汎用APIの既定値は18。適格でない候補は確率化前に除外する。抽選も世界、年月、主体から再現可能にする。イベントには実行行動だけでなく、全候補の評価値、確率、人格適合度、使用した国家6軸、統治者気質を保存する。

プレイヤー管理国の開戦・停戦は従来どおり承認待ちにする。AI確率は提案を生むが、プレイヤーの不可逆判断を代行しない。

## 9. V3更新順序

月境界では次の順序で一度だけ進める。

1. 地方人口・資産を既存周期で更新する。
2. 前月から保存された種族状態で国家意思決定を確率抽選する。
3. 外交、戦争、占領、抵抗を更新する。
4. 当月の行動、戦争損失、戦勝・敗戦、支配・迫害、平和、繁栄、交流をRaceStateへ反映する。
5. 経験と歴史アジェンダを減衰し、自然増減と統治者交代を反映する。
6. 年次・国境変動時に、気質構成と国家人物プロファイルを年代スナップショットへ保存する。

この順序により、当月の判断は月初の社会状態から出て、その帰結が翌月以降の判断分布を変える。

## 10. 表示

V3世界地図の国家詳細には次を表示する。

- 表示上の種族名と代表気質
- 強硬、服従、協調、自立の4比率とメーター
- 統治者の気質
- 国家へ合成済みの6軸
- 直近判断の上位確率分布
- 直近2件の歴史アジェンダ

年代を過去へ戻した場合は、その年次スナップショットに保存された構成を表示する。商会採用候補と採用済み人員には人物の気質名を表示する。

## 11. 保存と移行

- `generatedWorld.version`: 15
- `RaceDecisionWorldState.schemaVersion`: 1
- `V3WorldSimulation.version`: 2
- V3保存全体: 5
- 保存レジストリID: `race-decisions`

旧V3保存V3/V4は破棄せずV5へ移行する。種族状態がない保存では、その保存の世界シード、国家、人口から現在年月の初期RaceStateを補完する。既存フィールド、時計、外交、戦争、地方、商会、裏社会を巻き戻さない。

## 12. 決定論と安全条件

- 乱数源に`Math.random()`を使わず、世界シードと安定IDのハッシュを使う。
- 6軸、経験、人口、確率は保存・読込時に正規化する。
- 4気質人口の合計は常に総人口と一致させる。
- 最高評価の固定選択、種族IDだけを見た固定行動は禁止する。
- 人種的な本質や優劣として表示せず、「この世界・この時代の人口構成と歴史」として表示する。
- 国家AIの自律選択と、プレイヤーの不可逆な承認境界を混同しない。

## 13. 検証契約

最低限、次を自動検証する。

- 全種族が6軸を持ち、値域内である。
- 世界基礎値、人物抽選、国家確率選択が同一シードで再現する。
- 気質人口合計が100%で、迫害が協調型を強硬・服従へ分化する。
- 同じ戦争損失で強硬型比率が服従型より強く減る。
- 強硬なプロファイルは協調プロファイルより戦争確率が高い。
- 50年・600か月後もNaN、負人口、比率崩れがなく、気質・統治者・判断分布が更新される。
- JSON保存復帰後にRaceState、歴史スナップショット、統治者、判断確率が維持される。
- 1280×720と390×844の通常世界地図で比率、6軸、確率分布を確認でき、横溢れ、操作不能、コンソールエラーがない。

## 14. 現行の明示的境界

RaceStateは現在、種族全体の社会状態であり、同一種族の国家ごとの差は国家文化と統治者で表す。地方別・階級別の4気質人口はまだ持たない。汎用人物生成APIは商会候補と国家統治者へ接続済みで、既存の全固定NPCを遡って再生成しない。国家行動の確率評価は現行の自律外交・戦争14行動が対象で、プレイヤーの会話選択を自動抽選しない。
