# 2026-08-24 V3主要ループ通しプレイ・操作性レビュー

## 結論

Generation V3の新規生成から、徒歩、通常遭遇、個人戦、道具、交易、裏社会、軍務・集団戦、動的世界、保存復帰までを一つのセーブで接続して完走した。各システムの状態・時間・報酬は同じV3保存へ残り、軍務の延期と再開、集団戦結果のV3反映、裏社会と世界地図からの月進行も途切れなかった。

通しプレイで繰り返し再現した問題は、内容更新のたびにキーボードフォーカスが`body`へ消えることと、裏社会で届いた報告より画面上部の単独犯罪が先に選ばれることだった。表示やゲームルールは変えず、通常移動・遭遇・道具・交易・裏社会・世界地図を共通のフォーカス規則へ揃えた。

## 同一セーブで通した経路

- シード`v3-full-review-20260824`、エルフの主人公「巡回検証」で50年事前史を新規生成した。
- 旅商人へ徒歩で到達し、薬草を購入して別れた。通常遭遇の開始時と購入後は、商人の次の選択肢へフォーカスすることを修正後に再確認した。
- 街道の追剥との個人戦で退避を2回試し、いずれも失敗した後に攻撃で勝利した。HP10まで減った状態から薬草を使い、HP28、別の購入後はHP34まで回復した。
- 連邦首都エスラムで相場を記録し、穀物を仕入れ、後に売却した。更新後は選んだ「相場を記録」または同じ商品操作を維持し、操作が無効になった場合は次の実行可能項目へ移った。
- 窃盗成功、現地仲介人の発見、2名の採用、「灰路団」結成、恐喝の指示、1か月潜伏、完了報告まで進めた。月次後は「報告を確認」、報告後は次の作戦指示を優先するようにした。
- 連邦首都エスラムで軍務を受け、南東9歩の作戦地点へ矢印キーで移動した。一度「いったん離れる」で延期し、同じ地点から再開した。

- 「戦場を確認」を経てV3へ戻り、味方損耗136、軍功12、経験20、銀貨15が反映された。進行中軍務と遭遇は消え、`battle.result.applied`と`battle.result.projected`が同じ保存へ残った。
- 世界地図の国家・戦争・現象レイヤー、国家選択、誓暦267年4月の世界成立から現在までの年代つまみ、「現在へ戻る」、1か月進行を確認した。誓暦317年7月・34歩の保存要約から再開し、同じ主人公・場所・世界へ復帰した。

## 改善した操作規則

| 場面 | 修正前 | 修正後 |
|---|---|---|
| 新規開始・保存再開・通常移動 | 再描画でフォーカスが消える場合がある | 新しい現在地へ移す |
| 商人・人物遭遇 | モーダルは開くが本文へ落ちる | 最初の実行可能な遭遇操作へ移す。購入後も遭遇中なら操作へ残す |
| 道具 | 閉じるから開始し、使用後は本文へ落ちる | 使用可能な道具を先に選び、消費後は次の道具、なければ閉じるへ移す |
| 裏社会 | DOM上部の単独犯罪が常に先行する | 判断待ち→完了報告→月次進行→一味結成→仲介・採用→作戦指示→単独犯罪の明示順にする |
| 交易・商会 | 相場記録・売買・経営判断の再描画後に本文へ落ちる | 同じ操作を復元し、消滅・無効化した場合は判断待ちや次の実行可能操作へ移す |
| 世界地図 | 国家選択・現在復帰・月進行後に本文へ落ちる | 同じレイヤー、国家、現在復帰、月進行操作を復元する |
| パネルを閉じる | 道具・裏社会・交易は本文へ戻る | 開いたボタンへ戻す。世界地図の既存復帰規則とも一致させる |

優先項目は複数セレクターを一括検索せず、一つずつ順番に調べる。閉じた`details`内など実際には操作できない候補を飛ばし、同じデータ属性を持つ再描画後の要素を復元する。

## 画面確認

- 1280×720で新規生成から集団戦帰還、世界進行、保存復帰まで操作した。
- 390×844では文書・通常画面・道具・裏社会・交易・世界地図の横溢れが0だった。上部5操作、方向入力、パネルを閉じる操作、世界地図の表示中操作は44px以上だった。
- 844×390では文書・通常画面の横溢れが0で、方向入力は44×44pxを維持した。
- 同じブラウザーセッションを通してconsole warning/errorは各0件だった。

390×844と844×390はデスクトップChromeのビューポート検証であり、物理端末のタッチ感と実日本語フォント描画は未確認である。

## 自動検証

- フォーカス候補をDOM順ではなく明示順で探索すること。
- 道具・裏社会・交易を開いた入口へ戻すこと。
- 道具・交易・世界地図の再描画後に操作署名を復元すること。
- 新規開始、通常移動、通常遭遇で次の操作へ移ること。
- V3のフィールド、犯罪組織、商会、軍務、動的世界、ワールドエフェクト、保存・統合の既存回帰を維持すること。

## 検証境界

今回の同一セーブでは商会設立の長期条件、犯罪組織への昇格、誘拐・構成員拘束後の全分岐、個人戦の敗北、集団戦の敗北を再完走していない。商会・犯罪の上位分岐と敗北変換は既存の通常UIレビューおよびドメイン回帰を維持し、今回変更した全交易・商会操作には同じ再描画後フォーカス復元を適用した。集団戦は勝利、延期・再開、手動命令、戦果確認、V3帰還を実ブラウザーで確認した。
