# LEVIATHAN COVENANT — 個人から始まる立身出世・国盗りシミュレーション

V3は、生成済みの国家・地方・街道・集落を1マス単位の詳細フィールドへ投影し、一個人として実際に歩くブラウザ向けRPG試作です。既定入口の `index.html` とV3専用セーブを、今後の機能実装・画面改善・検証の唯一の開発正本とします。V2は比較・回帰確認用の `legacy-v2.html` として独立しており、V2だけへ新機能は追加しません。V2セーブとの互換は持ちません。

## V3の現在のゲームループ

- 先に192×120区画の概算世界を生成し、地形・水系・複合地理・探索地点・国家・地方・街道・集落を正本にする
- 概算世界1区画を8×8の詳細マスへ投影し、開始地点の周囲3×3チャンクだけを先に生成する
- 矢印キー、WASD、画面方向キー、隣接マスのクリックで、通行可能な隣の1マスへ進む
- 野外で敵を発見すると手前で停止し、探索中の詳細フィールドをそのまま使う個人戦へ入る。勝敗後は専用リザルトを挟まず同じ場所へ戻る
- アイテムを拾い、集落近傍で村人・冒険者・商人と遭遇する
- 実在する集落や街道で単独犯罪を行い、現地の仲介人から人員を雇って一味・犯罪組織へ発展する。人選と方針を決めて最大3作戦を委任し、月次報告、誘拐後の処遇、拘束された構成員への対応を選ぶ
- 集落中心まで歩いて「交易・商会」を開き、六商品の仕入れ・運搬・売却を行う。二市場で実績を作ると、同じV3セーブで商会を設立できる
- 商会では生成国家の制度に応じて、共和国の届出、貴族社会の領主承認、評議会・神殿・氏族・官庁の審査を受け、人員、国境販路、現地出店、月次決算を進める
- 海岸・浅瀬・干潟、森林種、オアシス、峡谷、沼地、田畑、運河、火山、洞窟、鉱山、遺跡などを歩き、地勢ごとに異なる移動時間・危険・遭遇候補を判断する
- 気温、降水、土壌水分、洪水危険、海岸・湿地・砂漠・火山から月ごとの現象域を生成し、長雨、暴風雨、降雪、吹雪、砂嵐、熱波、濃霧、降灰をフィールド演出と移動・遭遇補正へ一致させる
- 集落近辺で「軍務」を受け、地図に記された7〜12マス先の作戦地点まで実際に歩く
- 作戦地点では生成国家の部隊を率い、従来の参陣人物・陣形・初期配置・兵站・20×14戦術盤・戦果画面を使う。決着後は損耗、軍功、経験、銀貨をV3へ持ち帰り、生成戦争中なら兵力・士気・前線進捗にも戦果を反映する
- 新規生成時に50年の事前史を月次で進め、国家の外交判断、戦争、停戦、領土移管、周縁地方の独立を現在の国境へ反映する
- 各種族の強硬・服従・協調・自立の人口構成が、戦争損失、迫害、支配、平和、繁栄、交流で変化する。同じ人口を地方・階級・信仰の3方向でも集計し、国家AIは現在の地方構成、歴史、統治者、利益・危険・脅威・関係から行動確率を決める
- 「世界地図」で国家／地形／地方／戦争／現象レイヤー、国家詳細、年代記、過去の国境を確認し、世界だけを1か月または12か月進める
- 「世界地図」で概算世界の国家・街道・集落と詳細マップ上の現在地に加え、現在国の国家形態・政治制度・元首・首都、種族の4気質比、地方・階級・信仰構成、6つの意思決定軸、長期均衡、直近判断の確率、最寄り集落の都市機能を確認する
- 首都、地方政庁、商業・交易・港湾・鉱山・工芸・農業・城塞・国境・宿場などの都市機能が地勢と交通から決まり、近傍の商人・冒険者比率と商人価格へ反映される
- 歩行、世界地図、商会、裏社会は同じゲーム時計と月境界を使う。時間を進めた領域は`ActionResult`自身が宣言するため、どの画面から月を進めても各システムを一度だけ進行し、12か月観測の出来事も実際の発生月を保ってV6セーブへ保存する
- 移動先周辺を優先しながら、待機中に離れたチャンクも1区画ずつ生成して端末内へ保存する

詳細な生成・保存境界は [V3設計](./V3_DESIGN.md)、V2世界構築の共有境界と実画面検証は [V2世界構築・V3統合レビュー](./docs/gameplay-reviews/2026-08-24-v2-world-generation-v3-integration.md)、種族変容と確率判断は [実装仕様](./docs/superpowers/specs/2026-08-24-race-transformative-probabilistic-decision-system.md)、システム間の規格化と検証は [ゲームシステム規格化・統合レビュー](./docs/gameplay-reviews/2026-08-24-system-integration-rationalization.md)、複合地理の生成条件と実画面検証は [天地創造・複合地理レビュー](./docs/gameplay-reviews/2026-08-24-terrain-world-creation.md)、気象・天体・戦争を種族、戦闘、出現、市場へ接続した結果は [種族作用型ワールドエフェクトレビュー](./docs/gameplay-reviews/2026-08-24-race-reactive-world-effects.md) を参照してください。

## 画面方針

- V3の通常画面は、RPG型のフィールド、主人公ステータス、現在地、メッセージ、方向入力を一画面へ固定する。PCと390×844の縦画面で同じ1マス移動を維持する。
- V3の世界情勢は192×120の概算区画と地方を処理単位にし、1536×960の詳細マスを月次で総当たりしない。詳細マスは歩行時の決定論的投影、国家判断と国境は概算世界の保存状態として分離する。
- 個人戦は通常フィールド内で攻撃・退避を行う。部隊・軍勢による集団戦だけは、従来の戦闘前編成・兵站・戦術盤・戦果画面へ遷移する。
- 以下の画面方針は `legacy-v2.html` に保存したV2画面の仕様である。
- スマートフォンと縦長タブレットの本編は縦画面専用。狭い横画面では「縦画面で開始」ボタンが全画面化と縦向き固定を実行し、API非対応時は手動で縦向きに戻す案内をアプリ内に表示する。PCの横長表示は維持する。
- 地図を常設の主画面とし、操作・人物・能力・統治情報はドロワーまたは詳細画面に収納する。
- スマートフォン縦向きでは「高さ94pxの二段上部バー／中央地図／高さ64px＋安全領域の下部ナビ」を画面内へ固定し、ページ自体はスクロールさせない。長い情報は横幅いっぱいの下部シート内だけをスクロールし、上側へ地図を残す。
- 下部ナビは「世界／人物／統治／国制／評定／その他」の6枠とし、追加機能は「その他」のポップアップへ集約する。PCでは従来の上部コマンドバー＋左レールを維持する。
- 上部の「現在の目標」は説明欄ではなく、次の実行地点へ直行する操作とする。`N` で現在目標、`1`〜`6` で主要画面を開き、同じ情報を探し直す往復を減らす。
- 集落の施設では実行できる行動と依頼・仲間編成を先に出し、条件未達の行動は理由付きで折りたたむ。施設を開いた直後は主要操作へフォーカスし、`Esc` は「施設→施設一覧→地方地図」の順で一段ずつ戻る。

## 開発世代

- **ver1**: この方針決定時点の現行システム。プロトタイプとして比較・検証の基準に固定します。
- **ver2**: 戦略地図と地点選択型の移動を持つ比較アーカイブ。`legacy-v2.html` に固定し、回帰確認以外の開発対象にしません。
- **ver3**: 現在と今後の唯一の開発正本。旧移動方式を撤廃し、概算世界を入力にした1マス歩行フィールドを独立セーブで動かします。

ver2の立身出世・国家運営仕様は比較とV3への再接続候補のため残しています。再利用する場合もV3の入口、フィールド上の到達条件、状態、UI、セーブへ接続した時点を実装完了とします。詳しい判断基準は [VER2_DIRECTION.md](./VER2_DIRECTION.md)、生成世界を正本とする処理粒度と離席判断の境界は [WORLD_SIMULATION_POLICY.md](./WORLD_SIMULATION_POLICY.md) にまとめています。

## ゲームの目的と動線

以下は主にV2比較アーカイブの機能台帳です。V3へは一括移植せず、1マス歩行で意味を持つ機能から段階的に再接続します。個人交易、商会経営、犯罪組織はV3にも接続済みです。この台帳だけへ追加した機能は現行V3の完成機能として扱いません。

通常プレイでは、領地も私兵も持たない本人だけの状態から開始します。「世界」の個人マップで周辺を探索し、発見済みの近隣地点へ移動して村やダンジョンへ入ります。村では酒場、町以上では冒険者ギルドから依頼を受け、酒場でパーティーを集め、現地で達成してから同じ窓口へ報告できます。一方で身分にかかわらず市場を使い、土地ごとの相場を聞いて品物を仕入れ、別の集落へ運んで売ることもできます。これらの往復で武勲・地域別の名声・財産・地域功績を得て仕官先を開きます。仕官後の軍務は即時成功ではありません。期限・作戦地域・禁止事項を持つ命令を受け、作戦、兵站、参陣者を決め、実際に地方を移動して戦術戦闘を行い、負傷と損害を抱えて受命地点へ帰還・報告します。勝敗、期限、損害による評価を満たしたときだけ指揮官・領主へ進みます。

統治対象は `jurisdiction（管轄範囲）` で管理します。同じ統治画面が、所領、官職、主君からの期限付き委任、中央の禁止令に応じて段階的に拡張されます。領主が全国政策へ関与するときは直接実行ではなく建議となり、採用されても実施主体は主君と中央政府です。独立後は別画面へ切り替えず、同じ統治画面の対象が新国家全体へ広がります。

序盤から領主就任までの最小プレイループは次のとおりです。

1. 個人マップで「探索」し、発見済みの近隣村へ「移動」して入る
2. 村の酒場（町以上ではギルド）で依頼を受け、酒場で仲間を集めてパーティーを編成する
3. 依頼を達成し、受注した窓口へ報告して功績を得る
4. 使節の注目、偶発的な救命、武術大会、人物紹介などの経路から従士として仕官する
5. 主君の討伐命令を受け、作戦・兵站・参陣者を決めて作戦地域へ実移動し、戦術戦闘後に帰還報告する
6. 騎士・部隊長として、期限と許容損害を守りながら辺境救援軍を指揮する
7. 城将として預かった城で、予算・担当者・工期を持つ所領事業を完成させて男爵・城主となる
8. 加増、家臣への論功、複数軍戦役、地方統治を重ね、伯爵、侯爵、公爵、摂政へ進む
9. 正統性と家中・領民の支持を得て、独立または戴冠により君主となる

画面左端の情報欄に「次にすること」と日付・資源をまとめ、この中で現在必要な一手を常に表示します。上部の「現在の目標」を押すか `N` を押すと、その説明に対応する集落、施設、依頼地点、戦闘、人物行動、統治判断へ直行します。通常表示は決定・理由・予測・危険を優先し、地図モード、縮尺、統治オーバーレイ、詳細アウトライナーは「専門台帳」で開きます。

## 機能台帳（V2比較アーカイブを含む）

以下にはV2でのみ利用できる歴史的機能も含みます。「V3」と明記した項目だけが現在の通常導線へ接続済みです。未接続範囲は [未実装・部分接続台帳](./UNIMPLEMENTED_FEATURES.md) を参照してください。

- 魔法12種・鍛錬技能13種の探究台帳。旅、探索、異なる敵との勝利、被害、瀕死勝利、撤退、治療、会話、仲間、依頼、戦利品、隠密行動、能力値を組み合わせた取得条件を常時表示し、魔法4枠・技能3枠へ装備して個人戦術戦闘へ持ち込める。魔法使用回数と戦果も次の会得条件へ連鎖する
- 戦術戦闘は4段階の操作手順と全味方の指示状況を常時表示する。魔法は装備済みの術だけを選べ、有効対象マス、範囲、対象ごとの予測効果、術者の疲労を確認してから発動する。解決時は攻撃の命中・外れ・損耗と術固有の範囲演出を盤面へ重ね、炎上・凍結・土壁は継続地形として残す
- 生成国家の7文化に8兵科を横断する軍制アーキタイプを実装。人間の諸兵科連携、獣人の群れ狩り、ドワーフの盾壁と工兵、エルフの射界支配、リザードマンの水路伏撃、ゴブリンの仕掛け散兵、巨人の少数突破を制約にしつつ、通常軍務の全国家ユニットは国家・任務・地形・シードから部隊名、出身、軍旗、訓練度、特性、経験、補正、魔法構成まで決定論的に生成する
- 称号・権限設計と通常UIを10位階すべてへ接続。個人、従士、部隊長、城将、城主、伯爵、侯爵、公爵、摂政、君主を、軍務、所領事業、論功、複数軍戦役、家中・領民支持、正統性によって順に通過できる
- 日々の空腹・疲労・食料・負債と、日雇い／運送／護衛の期限付き生業、同行者の月給・要求・離脱を、生成世界の時計と地域移動へ接続
- 城将以降は予算・担当家臣・工期を持つ所領事業、功績に応じた家中恩賞、二軍団の戦役、六つの生涯目標、後継者指定と同一世界の世代継承を人物画面から操作できる
- 生成集落で家・倉庫・個人商店を取得し、商品別重量、保管容量、仕入原価、販売価格、月次収支、維持費滞納・閉店を同じ個人交易へ接続
- 個人交易で二市場の信用と利益を作った後、隊商本位・店舗本位・人脈本位から方針を選んで商会を設立できる。共和国の届出、貴族社会の領主承認、評議会・神殿・氏族・官庁の審査と義務を国別営業資格として経営判断へ加え、番頭・仕入役・隊商頭・護衛頭の採用、商品別販路、現地出店、月次人件費・上納・損益、街道事故への三つの対応を同じ人物年代記へ接続
- 実在同行者の旅・届け物・実戦の個人クエストを、期限、承諾・保留・拒否、忠誠・士気・恐怖、失敗後の継続へ接続
- 生成所領で領民・名望家・商人・家臣の四派案を討議し、妥協・各派支持・強行と月次結果を地域値・反乱圧力・年代記へ反映
- 君主は実在外国地方への戦役で、同盟軍、最大5正面、軍団別補給、行軍、攻城、撤退、再建、講和、首都攻略、確認付き限定割譲・完全併合を扱える。既知の他国戦争への援軍・仲介と、併合後の抵抗政策・事件対応も同じ生成世界へ保存する
- 婚姻・家系図・相続争いは実装対象外。単純な後継者指定と同一世界の世代継承だけを維持する
