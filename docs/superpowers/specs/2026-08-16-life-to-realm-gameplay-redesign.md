# 生活から国家へ連続するゲームプレー再設計

## 2026-08-16 第一実装の反映

本仕様の七層を一度通して遊べる基線として実装した。日次生活と期限付き生業、同行者の賃金・要求・離脱、担当者と工期を持つ所領事業、功績に応じた家中恩賞、二軍団の大戦役、六つの生涯目標、同一生成世界を保つ後継・継承を `lifeToRealm` 状態へ統合した。軍務縦切りと合わせ、10位階は通常UIと共有APIの双方から順に到達できる。

これは最終的な厚みではない。家・倉庫・積載重量、個人商店、家臣派閥・婚姻、人質・講和、城攻めの戦術戦闘、複数世代の家系図は次段階である。現状節は再設計時点の不足記録として保持し、実装後の検証は [生活から国家へ 実プレイレビュー](../../gameplay-reviews/2026-08-16-life-to-realm-playthrough.md) と `tests/life-to-realm-system.test.mjs` を正本とする。

## 目的

本作の独自性は、冒険者生活と国家運営を別モードとして並べることではない。同じ主人公、同行者、地域、評判、負傷、借り、罪、所領を保持したまま、本人の生活から主君への奉公、領地経営、国家形成へ拡大することにある。

2026-08-16 の通常UI実地検証では、新規開始から独立君主まで約3分で到達した。状態遷移は成立しているが、会話反復と確定成功ボタンが中心であり、準備、時間圧力、失敗、損耗、競合する選択、人物からの反応が不足していた。本仕様は機能一覧ではなく、時間と因果で相互接続したゲームループを正本とする。

## 参照作品から採用する設計原則

### Elonaから採用するもの

Elonaの保存されたマニュアルでは、依頼が名声を基準に無限生成され、期限超過で失敗する。交易品には地域相場と荷車重量があり、名声は高難度依頼、カルマは犯罪者化、ランクは期限付きノルマ、毎月の給料と請求書は生活維持へ接続される。

本作へ採用するのは固有の数値や世界観ではなく、次の循環である。

1. 小さな行動が技能、所持品、評判、関係、時刻を同時に変える。
2. 成功して名声が上がるほど報酬だけでなく依頼難度、敵、責任、税負担も上がる。
3. 期限、空腹、疲労、積載、天候、負傷、支払いが、どの依頼を受けるかの判断を作る。
4. 善行、犯罪、失敗は別画面の数値ではなく、衛兵、店、依頼、ギルド加入条件を変える。
5. 主筋以外にも交易、採集、家、仲間、ギルド、犯罪など複数の生計が並行し、プレイヤーが次の目標を自分で決める。

参照: https://wikiwiki.jp/elona/マニュアル/page2

### 信長の野望から採用するもの

『信長の野望・新生』公式マニュアルは、任命と内政、時間進行、月次収入、出陣を一つの循環として説明している。家臣は領地を与えられて自律開発し、具申を行う。戦争は準備、行軍路、補給拠点、郡制圧、会戦、攻城へ分かれ、勝利は周辺外交や支配にも波及する。功績を挙げた家臣への恩賞、領地、二つ名が次の成長と忠誠へ戻る。

本作へ採用する原則は次の通りである。

1. 命令は即時効果ではなく、担当者、費用、所要時間、対象地域、完了条件を持つ。
2. 家臣は能力、性格、忠誠、野心、現地適性に基づいて提案し、委任後も自律行動する。
3. 戦争は戦闘画面だけでなく、情報、兵站、進路、集結、目的、撤退、論功までを含む。
4. 強い選択には必ず代償がある。商業重視は軍事を弱め、徴兵は支持を落とし、補給拠点は別の収入を犠牲にする。
5. 功績、恩賞、知行、忠誠、出奔、派閥が循環し、主人公だけでなくNPCも立身する。

参照: https://www.gamecity.ne.jp/manual/shinsei/wpk/jp/3300.html
参照: https://www.gamecity.ne.jp/shinsei/wpk/system/?tgt=sec8

## 本作の七つの入れ子ループ

### 1. 一日・身体ループ

移動、探索、戦闘、会話、労働は時刻を進め、空腹、疲労、負傷、保存食、松明、積載へ影響する。宿、野営、治療、食事には費用と安全性の差がある。天候と季節は移動時間、視界、遭遇、農産相場を変える。

現状: 保存食、疲労、負傷、移動時間は部分実装されているが、日次判断と失敗条件へ十分接続されていない。

### 2. 集落・生計ループ

掲示板で期限と危険を比較し、依頼、交易、採集、護衛、犯罪、休養から今日の仕事を選ぶ。報酬は現金だけでなく、技能成長、地域評判、ギルド功績、人脈、許可証、盗品、負債を含む。家賃、雇用費、税、治療費が定期支出となる。

現状: 依頼、交易、犯罪、市場、施設は存在する。しかし生活費、積載判断、期限失敗、複数依頼の競合、家・倉庫・給与箱がない。

### 3. 仲間・部隊ループ

仲間は装備枠ではなく、希望、恐怖、忠誠、賃金、負傷、役割、個人的依頼を持つ。誰を危険な任務へ連れて行くか、誰を休ませるか、戦利品や功績をどう配るかで関係が変わる。成長した仲間は後任、部隊長、代官、家臣へ連続的に昇格する。

現状: 勧誘、会話、パーティー、負傷、戦闘参加、昇進時の後任は存在するが、賃金、論功、拒否、離脱、自発的具申が弱い。

### 4. 奉公・軍務ループ

主君の命令は、依頼主、政治的理由、期限、対象地域、許容損害、支給物資、禁止事項を持つ。受命後、偵察、同行者、兵站、進路、作戦を選び、実際に現地へ移動して戦う。帰還後に勝敗、期限、損害、民間被害、命令遵守を報告し、信頼、武勲、恩賞、昇進、叱責、負債が決まる。

現状: 討伐命令と救援戦役は確定成功ボタンであり、この層が最も欠けている。

### 5. 所領ループ

所領は毎月、人口、金銭、食料、治安、支持、施設、徴募余力を生む。プレイヤーと代官は、徴税、備蓄、街道、警備、救恤、徴兵から限られた予算と人員を配分する。決定は翌月以降に効果を出し、地域事件、相場、移民、盗賊、反乱へ波及する。

現状: 統治コマンドと地域値は存在するが、多くが即時増減で、月次予算、担当者、工期、相反効果、住民の要求へ結ばれていない。

### 6. 家中・勢力ループ

家臣は知行、官職、恩賞、方針、相性を評価し、具申、競争、派閥形成、出奔、謀反を行う。戦争では複数部隊がそれぞれの補給と目的で行軍し、軍団長へ委任できる。外交は同盟、援軍、停戦、人質、婚姻、交易権を用い、弱小勢力ほど重要になる。

現状: 官職、委任、忠誠、野心、外交、戦争AIは個別に存在するが、主人公の通常UIから同じ家臣を評価して知行と恩賞を配る循環がない。

### 7. 年代記・継承ループ

事件は個人年代記と世界年代記に残り、人物の二つ名、敵味方、制度、地域記憶を作る。死亡や失脚で終わっても、家、後継者、弟子、国家制度、悪名の一部を次の人物へ引き継げる。

現状: 因果履歴と終局状態は存在するが、世代継承とプレイヤーが選ぶ遺産がない。

## 実装順序

### Slice 1: 奉公任務の縦切り

討伐命令と辺境救援を次の状態機械へ置換する。

`提示 → 受命 → 準備 → 目的地へ実移動 → 戦術戦闘 → 帰還 → 報告 → 恩賞・昇進／叱責`

最低限保存する値:

- 任務ID、種類、依頼主、受命地点、対象地点、期限
- 政治的理由、敵情報、勝利条件、許容損害、禁止事項
- 偵察／速攻／守勢の作戦
- 軽装／標準／増強の兵站と消費資源
- 参加した主人公、仲間、部隊
- 戦闘ID、勝敗、死傷、残存HP、民間被害、期限内か
- 帰還報告、主君評価、信頼・武勲・地域名声、昇進可否

### Slice 2: 日次生活と依頼市場

絶対時刻、空腹、疲労、宿泊、治療、依頼期限、掲示板更新、複数依頼、失敗を統合する。

### Slice 3: 家臣の具申と月次所領

統治命令を担当者付きプロジェクトへ変え、家臣の提案、予算競合、工期、月次結果、功績を導入する。

### Slice 4: 論功・知行・忠誠

軍務と統治の功績を人物別に蓄積し、恩賞、二つ名、知行、役職要求、出奔へ接続する。

### Slice 5: 複数軍と国家戦争

地域移動、補給拠点、部隊行軍、会戦、攻城、占領、講和を生成世界の支配状態へ接続する。

## 受け入れ基準

1. 通常UIから確定成功ボタンだけで従士から城主へ進めない。
2. 任務の対象は実在する生成地域で、実際に地図移動しなければ戦闘できない。
3. 作戦と兵站は資源、敵戦力、地形、損耗のいずれかを変える。
4. 戦術戦闘の実結果だけが任務結果となり、主人公・仲間・兵力の損耗が保存される。
5. 報告は受命地点でのみ可能で、期限、勝敗、損害、命令遵守から評価される。
6. 敗北や期限切れでもセーブは継続し、信頼低下、再任務、別経路が残る。
7. 任務の途中で保存・再読込しても、対象、準備、参加者、戦闘待ち、帰還待ちが一致する。
