# 2026-08-24 種族作用型ワールドエフェクト 実装・実プレイレビュー

## 結論

ワールドエフェクトを地図上の演出から、種族の生態と既存ゲームシステムへ作用する共通ルールへ拡張した。現行8気象、満月、新月、戦時物資高騰を一つの評価境界へ揃え、移動、遭遇危険、個人戦、生成国家の集団戦、霊体出現、市場価格・在庫へ実際に反映する。

## 共通評価契約

- `src/race-list.js` の各大分類・実種族が `worldEffectTags` を持ち、戦術側も `getTacticalPeopleDefinition` から同じ正本を読む。
- `src/race-world-effect-system.js` は作用中の現象と種族を受け、移動負荷、危険、攻撃、防御、機動、射撃精度、魔力、士気、疲労、霊体実体化を合成する。UI専用の判定は持たない。
- `src/v3-world-effects.js` は現在地の気象、主月の30日周期、夜判定をまとめ、移動用と戦闘用へ同じ種族応答を返す。第1日は新月、第15日は満月で、天体作用は20:00から翌04:59だけ有効となる。
- 個人戦では主人公と敵を別々に評価する。集団戦では作戦地点における両国家の `peopleId` を評価し、生成した全戦術部隊の有効能力へ合成する。
- 戦時市場は現在国が関与する戦争数と対象地方から強度を求める。穀物、薬草、鉄、塩を中心に商品別価格を上げ、在庫を減らし、表示と実際の購入・売却に同じ市場状態を使う。

## 現象別のシステム作用

| 現象 | 種族作用の例 | 接続先 |
|---|---|---|
| 長雨 | 水性・森林適応は負荷軽減、火性は攻撃・魔力低下 | 移動、危険、戦闘 |
| 暴風雨 | 風性は機動・魔力強化、通常飛行種は機動低下 | 移動、危険、戦闘 |
| 降雪・吹雪 | 耐寒種は防御・機動維持、変温種は活動低下 | 移動、危険、戦闘 |
| 砂嵐 | 乾燥・密閉・地下適応は軽減、飛行種は飛砂で弱体化 | 移動、危険、戦闘 |
| 熱波 | 火性・乾燥・非生体は疲労軽減、耐寒種は熱負荷増加 | 移動、危険、戦闘 |
| 濃霧 | 夜の妖魔を強化し、森林感覚は索敵低下を軽減 | 移動、危険、戦闘 |
| 降灰 | 火・土・密閉・地下性は耐性、水性は水源汚染で弱体化 | 移動、危険、戦闘 |
| 満月 | `LUNAR_DEMON` を持つ魔族系の攻撃・魔力・士気を強化 | 個人戦、集団戦 |
| 新月 | 霊体を攻撃可能な実体にし、決定論的な幽霊を出現させる | 出現、個人戦、集団戦 |
| 戦争中 | 交戦国の軍需・輸送圧力を商品別に反映 | 市場価格、在庫、実売買 |

## 通常UIの実プレイ

検証シードは `world-effects-browser-0`。1280×720で新規開始を選び、主人公をエルフ、名前を「エルフ検証」として50年事前史を通常画面から生成した。

1. 誓暦317年4月1日08:00の開始地点は長雨だった。現在地は「エルフ・森雨同調」、移動 `+15%`、遭遇 `+0.6pt` と表示され、世界地図にも同じ値と応答理由を表示した。
2. 東へ1マス進むと時計は08:00から08:22へ進み、ログは「東へ22分進んだ。密林。長雨の影響を受けている。森雨同調。」となった。表示移動時間、時計差、種族応答が一致した。
3. 世界地図の現象パネルは5現象域、主月「紅月」の新月、日中のため未作用、エルフへの「森雨同調」を同時に表示した。
4. 再読込後の開始画面は「エルフ検証・317年4月・1歩」を示し、「冒険を続ける」で08:22、エルフ、森雨同調を復元した。

## 新月出現の補助確認

現行UIには同日夜まで待つ専用操作がないため、新月だけは上記の通常プレイ保存を複製したブラウザ状態で、共通時計を同日20:00へ進めて確認した。この時計注入は通常導線の証明には含めない。

- 20:00になると現在地表示は「紅月新月（作用中）」へ変わり、同じ詳細マスに「新月の幽霊」が出現した。
- 東へ1マス離れて西へ戻ると、幽霊の手前で停止して通常フィールド内の個人戦になった。
- 1回攻撃すると敵HPは20から11、主人公HPは34から26となり、ログに「森雨同調・霊体実体化が作用した」と記録された。出現許可と敵側戦闘補正が同じ新月評価から届いている。

## 画面検証

### 1280×720

- 文書は `1280/1280px`、世界地図は `1280/1280px`、現象パネルは `346/346px` で横溢れ0。
- 現象レイヤー、現在地の長雨、主月の月相、エルフへの作用理由、5現象域を同じ画面で確認した。
- Escapeで世界地図を閉じ、起点の「世界地図」ボタンへフォーカスが戻った。

### 390×844

- 文書と通常画面は `390/390px`、フィールドは `390×327px` で横溢れ0。
- 方向キー4個はすべて `44×44px`。種族作用ラベルは「エルフ・森雨同調・紅月新月」を欠落なく保持した。
- 世界地図は `390/390px`、作業領域は `370/370px`、現象パネルは `368/368px` で横溢れ0。作業領域は高さ633pxの内部スクロールで、2213pxの全情報へ到達できる。
- 地図レイヤー5個はすべて高さ44px。新月の幽霊との個人戦でも地図、敵HP、現在地作用、攻撃・退避を同じ縦画面に保持した。

### 実行環境の境界

- 実Chromeのconsole warning 0件、error 0件。
- 検証ホストに日本語グリフを持つフォントがなく、スクリーンショット上の日本語は豆腐表示になった。DOMとアクセシビリティツリー上の日本語ラベル、値、寸法、操作、計算は確認したが、実フォントでの字形品質はこの環境では証明していない。
- 満月の魔族強化と戦時市場は、検証シードの開始時点に該当状態がなかったため実ブラウザでは発火させず、公開APIの決定論テストと実売買テストで確認した。

## 境界と次案

- V3新規主人公の通常選択は現時点で人間、エルフ、ドワーフ、オークの4種。共通評価は60実種族と大分類を扱うが、追加主人公種族の解禁条件は別機能とする。
- 月相は時計から導出するため保存を重複させない。戦時市場も動的世界の戦争を正本とし、市場へ戦争台帳を複製しない。
- 次の優先案は宿・港・観測所での予報と待機。翌日の気象と月相を確認して時刻を選べるようにし、外套、防塵具、護符、街道整備で種族弱点を軽減すれば、現象を準備と選択のゲームへ発展させられる。
