# V3 確率的国家判断と開発者システム（2026-09-08）

## デモ前のコードレビュー

対象は既定入口のV3、共有国家判断、月次世界、V6保存、新設の変数台帳と比較実行。独立した旧版ゲームは追加していない。

- 従来はsoftmaxの診断確率を記録しながら最終行動を厳密最大化で決めていた。V3の確率選択を一箇所に集約し、実際の確率、候補除外、点数内訳、抽選値、試行・モデル設定をイベントへ保存した。厳密方式は比較用に維持する。
- 五条件の投影と適用は既存の共有行動効果・同月の自然増減を共用。開戦、停戦、同盟の実行条件とプレイヤー承認を維持。承認待ちの代替行動は提案と区別し、その適用に抽選確率を付けない。
- JSON保存・復帰で負のゼロが正のゼロへ変わる点を検出。判断の点数と文化特性の丸めで0へ統一し、一括／毎月保存を挟む進行の厳密一致を確認した。
- 危機と直近市場の不足は地方の現支配国へ集計し、旧所有国に帰属した記録をそのまま使わない。翌月の危機や市場結果は先読みしない。
- 設定の宣言を型・範囲の正規化、入力フォーム、変数説明で共用。現行V6の任意項目worldSimulation.model v1へ保存し、不明な版の上書きを拒否する。設定保存が失敗した場合、現在の世界への適用も行わない。
- 比較はWeb Worker内の複製世界で実際のV3月次関数を使用。保存中の人物・時計・世界へ書き込まず、中止・画面を閉じる・ページ離脱でWorkerを終了する。再現用の開始状態と設定を結果と一緒に保存できる。
- 変数一覧は階層を遅延展開し、検索結果を50件ずつ表示して全件数を示す。ゲーム状態、生成地理、共通定義を対象にし、未知の分類を未分類と表示する。説明は分類・フィールド・設定定義で共用する。

## 確率・長期比較

`tests/v3-simulation-model.test.mjs` と `tests/v3-developer-system.test.mjs` の10件により、4,000試行の頻度と表示確率の整合、候補順に依存しない再現性、危機制約、各要因の重みによる確率変化、読み取り専用一覧、比較中の原本不変、厳密方式の再現、V6保存を確認した。

`node scripts/audit-v3-probability.mjs` は3地形×6設定×60か月と3地形×600か月の計21ケース・2,880世界月を検証。国家五条件0〜100、市場の非負在庫・正の価格、非負人口と集計誤差、実際の選択と表示確率を確認。結果は `docs/reports/2026-09-08-v3-probability-audit.json`。

追加で旧固定地形の600か月を6設定で比較した。以前の固定3シードが確率方式では平和になったため、地形を広げて検証したところ、`v3-probability-audit-0` は確率方式で戦争1件・厳密方式では0件（60か月）、他の2地形は平和だった。新方式の50年史でも戦争あり1・なし2に分岐。特定シードの旧結果へ寄せるための強制開戦は追加していない。旧50年史の戦争・停戦の再現は厳密モードで保持し、新方式の回帰は戦争と平和の両方を持つ地形群で検査する。

係数はゲームの仮定であり、現実世界の統計推定値ではない。人間のユーザー評価の向上はこの自動検証だけでは確定できない。

## デモで発見した修正

- 設定を下までスクロールすると比較・変数へ移りにくかった。見出し・タブを固定し、タブ変更と再度開く際に先頭へ戻す。
- 長時間の比較中にも本編の詳細地形生成が進み、生成済み区画と保存日時だけが更新されていた。開発者画面では裏側の地形生成を一時停止して、検査中の状態を固定する。再実行した4試行×6か月と書出し前後で保存JSON全体が一致し、閉じた後は地形生成が再開した。全変数JSONは不要な字下げを省き、世界・作用説明を保持して108,517,085バイトから56,286,457バイトへ削減した。
- 50年史後の被災国は食料7、他の四条件0となり、実際の市場には1.1か月の穀物があるのに飢饉が繰り返されていた。地方市場ごとの備蓄0.75か月以上・未充足10%以下を翌月の回復判定へ接続。別地方の在庫を使わず、数値0を55へ補完する誤りも修正した。通常操作で12か月進め、世界の活動中飢饉6→1、被災国の食料7→37、財政0→7、防衛0→5、主権0→2を確認。結束はまだ0であり、国家全体の即時回復を保証しない。
- 修正後に850件と21ケース・2,880世界月を再実行。50年史は戦争あり1・平和2を保ち、最弱値は地形0で0→55へ改善。修正前記録は `docs/reports/2026-09-08-v3-probability-before-relief.json`、最終結果は同日の `v3-probability-audit.json`。2回の監査と6設定の比較で、計9,360世界月を試した。
