# 2026-08-24 V2世界構築・V3統合レビュー

## 目的

V2で確立した地形、河川、国家、地方、街道、集落の世界構築アルゴリズムをGeneration V3の新規開始へ統合し、両世代で生成処理が分岐しないことを確認する。V3の1マス歩行、画面状態、専用セーブは独立したままとし、V2から再利用する範囲は生成された概算世界に限定する。

## 統合境界

- `src/world-generation.js` を生成パイプラインの正本とし、同期・非同期生成、生成条件の正規化、キャッシュ、進捗通知を集約した。
- V2の `buildGeneratedWorld()` / `buildGeneratedWorldAsync()` は、既存の保存移行と地方移動APIを維持する互換ラッパーとして共有パイプラインを呼ぶ。
- V3の `prepareWorld()` は共有パイプラインを直接呼び、生成された概算区画を `v3-field-system.js` の8×8詳細マスへ投影する。
- 生成ランタイムへアルゴリズムID、版、`sourceGeneration: "v2"`、正規化済み生成条件を付け、ブラウザから実際の接続先を確認できるようにした。
- V2の地点選択型移動、画面、セーブはV3へ取り込んでいない。

## 自動検証

- 固定シードのV2互換APIとV3共有APIが同一ランタイムを返すことを回帰テスト化した。
- 同じランタイムから地形、国家、地方、街道、集落がV3詳細世界へ投影されることを確認した。
- `npm run check` でソース93ファイルの構文検査と全764テストに成功した。

## 通常UIでの確認

Chromium headlessで固定シード `v2-v3-browser-contract` のV3新規世界を作成した。共有ランタイムは192×120の23,040概算区画、7国家、59地方、218街道、134集落を持ち、V3側は1536×960の詳細座標系へ投影した。

開始地点の周辺には沼地、運河、田畑、森、街道、首都の通り、住民が現れた。「東へ進む」で田畑へ1歩移動すると、第1日08:00から08:08へ進み、現地住民との遭遇も同じ詳細フィールドで発生した。世界地図では国家色、地方、街道、集落、現在地、国家詳細、年代記を確認した。

ページを再読込し、「冒険を続ける」から復帰すると、プレイヤー名、1歩、08:08、生成シードと `sourceGeneration: "v2"` を保持したまま同じV3フィールドへ戻った。

## 表示検証

- 1280×720: ページ横溢れ0px。世界地図キャンバスは752×470px。console warning/error各0件。
- 390×844: ページ横溢れ0px。フィールドは390×327px、世界地図キャンバスは364×228px。世界地図、道具、方向キーは44×44px。console warning/error各0件。
- ブラウザセッションとローカルHTTPサーバーは検証後に終了した。

## 残る境界

- 実ブラウザ確認はChromium headlessのPC・縦画面エミュレーションであり、物理端末では未確認である。
- V2のUI・状態・セーブ互換をV3へ追加したものではない。V2は引き続き比較アーカイブで、V3の通常導線と専用セーブが開発正本である。

## 結論

V2の世界構築アルゴリズムを独立した共有パイプラインへ抽出し、V2互換経路とV3新規開始が同じ生成結果を使う構造へ統合した。これにより生成仕様の二重実装を避けつつ、V3固有の1マス歩行、詳細生成、UI、保存境界を維持できた。
