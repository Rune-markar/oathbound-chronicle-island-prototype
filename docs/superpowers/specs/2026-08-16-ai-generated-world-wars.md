# 生成国家間の自律戦争仕様

## 目的

生成国家の「限定国境戦争」を外交イベント名だけで終わらせず、同じ生成地方・国境・国家状態を正本に、攻撃、防衛、損耗、講和、支配変更まで月次進行させる。プレイヤーが関与しない戦争は世界側で自律進行する一方、プレイヤー支配国の不可逆判断と、プレイヤーがまだ知り得ない情報は自動確定・全知表示しない。

## 正本と責務

| 正本 | 責務 |
|---|---|
| `geopolitics` | 国境危機、国家プル、開戦・停戦合意、休戦期間 |
| `worldWars` | 当事国、目的、ドクトリン、最大二正面、戦力、補給、士気、損失、戦役段階、戦史 |
| `regionalDomains` | 各生成地方の現在支配国と、講和による実際の支配変更 |
| `intelligence` | プレイヤーが噂または現場で知った戦争イベント |

`worldWars` は地形タイルや国家全体を複製せず、IDと戦争中に変化する小さな数値だけを保存する。旧保存に台帳がなければ空の台帳として初期化し、旧地政台帳ですでに交戦中のAI二国が実在国境を持つ場合は現在状態から戦争を復元する。進行中のプレイヤー戦役と同じ二国関係は復元対象から除外する。

## 開戦条件

既存地政処理が同じ月に `war_started` を成立させ、二国間関係が非戦争から戦争へ変わった場合だけ新規戦争を作る。対象国間に、現在の地域支配に基づく実在の陸上国境が必要である。同じ国家が同時に複数の自律戦争へ参加することはできない。

攻撃目標は、防衛国のうち攻撃国領と隣接する地方から、人口、首都、地域中枢、移動負荷を比較して選ぶ。主攻正面に加え、別の隣接目標がある場合だけ支援正面を置く。

## 国家理論

攻撃側は次の条件を使う。

- 決戦突破：高い即応と攻勢意図を短期突破へ集中する。
- 回廊戦争：交易力が高い国家が街道・市場路と補給維持を重視する。
- 資源圧迫戦：食料または備蓄不足から近隣の生産地方を狙う。
- 限定圧力：拡大を抑え、一地方と有利な講和だけを狙う。

防衛側は次の条件を使う。

- 城砦網防衛：険阻地形と国境障壁を連結して消耗を待つ。
- 機動防御：高い即応と国力を予備隊・局地反撃へ使う。
- 縦深防御：前線を段階後退させ、損耗を抑えて第二線で止める。

## 月次段階

1. `mobilizing`：正面を形成し、初期補給を消費する。
2. `campaigning`：攻撃側と防衛側が各月の行動を選び、戦力比、地形、ドクトリン、補給、決定的揺らぎから正面進捗と双方損失を更新する。
3. `siege`：最も進んだ正面の地方で強襲・封鎖・交渉と固守・反撃・撤収を比較する。
4. `settlement`：限定割譲、侵攻撃退、攻撃側撤退、国境維持、相互停戦のいずれかを確定する。

攻撃側補給または戦力が限界を下回れば撤退する。正面突破または防衛戦力崩壊で攻城へ入り、九か月を超えた野戦は平均進捗から勝利または膠着を判定する。戦争コストは当事国の即応、備蓄、食料、結束へ返す。

## 講和と地域移転

攻撃側勝利では主目標一地方だけを `transferRegionControl` で割譲する。国家人口、地方数、拠点所属、国境線は `regionalDomains` から再計算される。その他の終結では国境を維持する。終結時は二国間関係を非戦争へ戻し、12か月の休戦を設定する。

## プレイヤーと情報の境界

`simulationFidelity.playerControlledNationIds` に当事国が含まれる戦争は `awaiting_player` とし、不可逆判断を進めず戦略判断待ちへ積む。AI対AIだけが自動講和・割譲を行う。

世界情勢画面は `intelligence.eventId` と戦争イベントを照合し、一件でも知った戦争だけを表示する。未取得の国家内部状態、戦力、ドクトリン、進捗は表示しない。開戦後に噂を聞くか、戦場または隣接地方に居合わせると、既知戦争として攻守ドクトリンと前線状況を確認できる。

## 決定性と上限

同じ世界シード、戦争ID、年月、正面IDから月次揺らぎを再現する。戦争は最大12件、終結戦史48件、戦争イベント192件、正面は一戦争あたり最大2件に制限する。重い地形データは保存しない。

## 今回含めないもの

- 固定戦域盤と固定都市占領の廃止
- プレイヤー戦役とAI戦争の完全な共通エンジン化
- 三正面以上の兵站
- 進行中のAI戦争へのプレイヤー参戦・援軍・仲介操作
- 首都陥落による国家滅亡、従属国化、全面併合

これらは `UNIMPLEMENTED_FEATURES.md` の「生成戦争エンジンの全面統合」に残す。

## 受入確認

- 開戦は実在国境だけで成立し、攻守ドクトリンと一〜二正面を持つ。
- 同じ入力と年月から同じ戦争状態を得る。
- 月次で行動、進捗、補給、士気、損失が保存される。
- 攻城、撤退、停戦、講和が完了し、限定割譲だけが実地方支配を変更する。
- 一国家が同時に二つの自律戦争へ参加しない。
- 旧保存は空台帳へ移行し、保存状態は地形タイルを含まない。
- 未知の戦争は通常UIへ出ず、取得済み戦争だけ表示する。
- プレイヤー支配国の不可逆判断は自動実行されない。
