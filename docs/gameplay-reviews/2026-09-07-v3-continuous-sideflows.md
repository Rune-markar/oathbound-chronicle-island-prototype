# V3通常操作の交易・任官・軍務往復確認

2026-09-07、統合worktreeのコードレビューと修正後に実施。Playwright CLI専用セッション `continuous-sideflows` を使用し、`http://127.0.0.1:4207/` の既定入口から操作した。世界は既定の192×120・7国家・50年史、シード `v3-continuous-sideflows`、主人公はドワーフの「流通試験者」。主画面は390×844、PCの再確認は1366×900。

状態・保存内容への書込み、所持金の事前加算、座標の書換えは使っていない。画面の通常ボタンで移動・取引・任官・軍務の引渡しを実行し、状態の読取りで保存結果を確認した。

## 確認した流れ

1. 新規人物の開始位置1208,424から東4・南4の8歩で連邦首都メルヴィアの市場へ到着した。
2. 「交易・商会」で相場を記録し、穀物を1個仕入れて1個売却した。所持金は12から11.3、購入数1・売却数1、仕入費用4.1・売上3.4・実現利益-0.7を記録した。在庫と積荷も実際の取引に対応して変化した。
3. 「人物史・統治」から集落の一日仕事を3回、地方の委託、地方統治の任官へ進んだ。総督段階、所持金13.3を確認した。任命国の準備金が0でも、一日仕事や月送りが残り、進行不能にはならなかった。
4. 人物史画面はEscapeと閉じるボタンの両方で通常画面の操作を再開でき、フォーカスが「人物史・統治」へ戻った。再読込後の「冒険を続ける」で総督段階・所持金・世界時計・座標・歩数・取引実績が保持された。
5. 現地の軍務「メルヴィア西境地方・侵入軍迎撃」を受け、東8・南3の11歩で1220,431の作戦地点へ到着した。「いったん離れる」で延期した後に再開し、専用集団戦の戦闘前編成へ入れた。「V3作戦地点へ戻る」で同じ作戦地点と保存内容へ戻り、再び延期して市場まで歩いて戻れた。
6. 操作性修正後も同じ任務へ歩いて再訪し、戦闘前編成を再読込、楔形陣と自動配置を選択、通常画面へ戻る操作を再確認した。最後に市場へ戻って再読込し、総督段階・所持金13.3・位置1212,428・52歩・時計8046分を保持していた。

集団戦の戦闘開始・決着まではこの補助確認の対象にしていない。終局の二経路は別の通しプレイ記録を参照する。

## デモで見つけた操作性の修正

- 市場の危機説明が390px画面を大きく占有し、「相場を記録」も折り返していた。市場への影響を折り畳み詳細へ変更し、初期状態では要約を表示する。詳細本文の展開、相場記録による再描画後の展開状態保持、再折り畳みを確認した。相場記録ボタンは102×44pxで一行表示となった。PCでも商品一覧と個人商売欄が正常に並び、画面・内容の横溢れはない。
- 軍務準備の自動／手動配置ボタンが38px、陣形ボタンが約41.1pxだった。`styles.css` の `.battle-placement-mode button` と `.battle-preparation-formations button` に最小高さ44pxを指定した。再読込後、対象5ボタンすべてがスマートフォン・PCの双方で44pxとなり、陣形と配置操作、編成中止から通常画面への復帰も成功した。配置盤のマス寸法は変更していない。

確認範囲の横溢れは0、最終consoleはerror・warningとも0件。専用ブラウザを閉じ、共有サーバーは別担当の検証用に保持した。
