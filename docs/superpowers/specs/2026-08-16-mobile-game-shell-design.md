# スマホ横向き本編の固定画面設計

## 状態

- 仕様決定日：2026-08-16
- 対象：ゲーム本編の横向きスマホ表示
- 状態：実装済み
- 対象外：開始画面、開発者メニュー、PC向け既存レイアウト

## 実装・検証

- `index.html`、`src/app.js`、`styles.css` に固定三層シェル、下部ナビ、「その他」、内部スクロールドロワーを実装した。2026-08-19の可読性改修で上部42px、下部50px、最大72vwのドロワーへ拡張した。
- `tests/map-visual.test.mjs` に固定寸法、ナビ構成、地図状態保持、凡例初期状態、アクセシビリティの回帰検査を追加した。
- 667×375、740×360、844×390、915×412でページ縦横オーバーフローがないこと、1280×720でPCレイアウトを維持することをブラウザ確認した。

## 背景

現行の844×390表示では、上部64pxと左側72pxの常設領域に加え、現在地、通知、時刻、凡例が地図上で競合している。ページ自体の縦スクロールは抑制されているが、地図の視認性と主要操作への到達性が悪い。

本変更では、ゲーム本編を「上部ミニバー・中央地図・下部ナビ」の三層へ再構成する。地図と外枠はスクロールさせず、詳細情報はドロワー内部だけでスクロールさせる。

## 目的

- 横向きスマホでページスクロールを発生させない。
- 地図を画面の主役として最大化する。
- 人物、次にすること、年月・時刻を常時確認できる。
- 既存機能を削除せず、下部ナビと「その他」へ収納する。
- 詳細を閉じたあとも地図の位置、縮尺、選択地点を維持する。

## 非目的

- 開始画面や開発者メニューの再設計。
- PC表示の全面的な再設計。
- ゲームシステム、保存形式、権限解禁条件の変更。
- 詳細パネル内の情報量削減。

## 画面構造

### 上部ミニバー

- 高さは42pxを基準とする。
- 左に人物名、中央に「次にすること」、右に年月・時刻を置く。
- 人物名は既存の人物・経歴画面への入口を兼ねる。
- 長い「次にすること」は一行で省略し、タップすると理由と詳細をドロワーに表示する。
- 資源、地位、専門台帳、バックメニュー等は常設せず、対応するドロワーへ移す。

### 中央地図

- 上部42pxと下部50pxを除く全領域を使用する。
- 地図のドラッグ、タッチスワイプ、地点選択、移動操作は維持する。
- 現在地と時刻の重複表示を廃止する。時刻は上部ミニバーを正本とする。
- 現在地ラベル、重要通知、地点確認は地図端の小型オーバーレイとし、同じ角へ積み重ねない。
- 凡例は初期状態で閉じ、必要時だけ地図上の小型ボタンから開く。

### 下部ナビ

- 高さは50pxを基準とし、安全領域を加味する。
- 並び順を `世界 / 人物 / 統治 / 国制 / 評定 / その他` に固定する。
- 画面解放前の機能は位置を変えず、非活性または解放条件表示とする。
- `その他` に支出、都市、町政、外交、軍事、専門台帳、バックメニューを収納する。
- 現在表示中の項目は文字と背景の両方で識別し、色だけに依存しない。

## ドロワー

- 下部ナビから左側ドロワーを開く。
- 外枠と地図は固定し、ドロワー本文だけ `overflow-y: auto` とする。
- ドロワーの幅は横向きスマホで画面幅の72%（最大560px）を上限とし、地図の一部を常に残す。本文は11px未満へ縮小せず、項目は内容に応じて一列または読みやすい複数列へ組む。
- 閉じるボタン、背景領域のタップ、Escapeで閉じられるようにする。
- ドロワーを閉じても地図のパン位置、縮尺、選択地点、移動確認状態を再生成しない。
- 別項目を選んだ場合はドロワーを閉じず、本文だけを切り替える。

## 状態とデータの扱い

- 既存の表示状態を正本とし、新しいナビ専用のゲーム状態は増やさない。
- ナビ選択は既存の `data-panel`、`data-shortcut-tab` と表示関数へ接続する。
- UI切替だけでは既存地図を再描画しない。地図データが変化した場合だけ既存の描画経路を使う。
- 解放条件と権限判定は既存モデルを利用し、CSSだけで操作可能にしない。
- 保存データのスキーマは変更しない。

## 画面幅ごとの扱い

- スマホ横向き：上部42px、下部50px、中央地図の固定三層構造を適用する。
- 基準表示：667×375、740×360、844×390、915×412。
- 縦向き：既存の横向き案内を維持する。
- PC：既存レイアウトを維持し、本変更のスタイルを横向きスマホ条件内へ限定する。

## 異常系と縮退

- 「次にすること」が未取得の場合は空欄にせず「次の行動を確認」と表示する。
- 日付・時刻が未初期化の場合は既存の初期値表示を使い、推測値を生成しない。
- 非活性項目を押した場合は解放条件を短く表示し、空のドロワーを開かない。
- ドロワー本文が長い場合だけ内部スクロールを許可し、ページ全体へスクロールを伝播させない。

## アクセシビリティ

- 下部ナビは高さ50px、上部ミニバーは高さ42pxを確保し、主要操作は十分な横幅と11px以上の文字を持たせる。ドロワーの閉じる操作は40px四方、本文内の操作は高さ40px以上とする。
- 現在の主要画面には `aria-current="page"`、ドロワーを開くボタンには `aria-expanded`、未解放項目には `aria-disabled="true"` を設定する。
- ドロワーの開閉状態を `aria-expanded` と `aria-hidden` で同期する。
- キーボードフォーカスをドロワー内へ移し、閉じたときは起点ボタンへ戻す。
- `prefers-reduced-motion` ではドロワー遷移を無効化する。

## 検証

- 静的回帰：上部・下部の項目、固定順序、非活性状態、ARIA属性を検証する。
- 状態回帰：ドロワー開閉と項目切替で地図の位置、縮尺、選択地点が維持されることを検証する。
- 権限回帰：未解放機能が既存の認可境界を迂回しないことを検証する。
- 実ブラウザ：844×390と740×360で `scrollHeight === clientHeight`、横方向のはみ出しなし、地図オーバーレイの重なりなしを確認する。
- 操作確認：各下部ナビ、その他メニュー、ドロワーの閉じる操作、地図スワイプ、地点選択を確認する。
- PC回帰：代表的なPC幅で既存の操作導線が変わっていないことを確認する。
