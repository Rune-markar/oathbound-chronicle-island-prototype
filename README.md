# 誓界記 — 個人から始まる立身出世・国盗りシミュレーション

エルドリア大陸の一個人として始まり、依頼、仕官、軍務、封建、中央政治、寝返り、独立を通じて自らの立場を作るブラウザ向け戦略ゲーム試作です。世界・国家・都市圏・村々のシミュレーションはプレイヤーの所有物ではなく、本人がその中で関係と権限を獲得していく舞台です。

## 開発世代

- **ver1**: この方針決定時点の現行システム。プロトタイプとして比較・検証の基準に固定します。
- **ver2**: 現在の開発対象。以後の修正・追加・検証は、明示的な指示がない限りver2を対象とします。

ver2では、平民・浪人・傭兵から従士、騎士、城主、地方領主、公爵、摂政、君主へ進む立身出世を主軸にします。完全中央集権化は国家を得た後の長期目標であり、個人の出世段階を一つ増やすものではありません。詳しい判断基準は [VER2_DIRECTION.md](./VER2_DIRECTION.md) にまとめています。

## ゲームの目的と動線

通常プレイでは、領地も私兵も持たない本人だけの状態から開始します。「世界」の個人マップで周辺を探索し、発見済みの近隣地点へ移動して村やダンジョンへ入ります。村では酒場、町以上では冒険者ギルドから依頼を受け、酒場でパーティーを集め、現地で達成してから同じ窓口へ報告します。この往復で武勲・地域別の名声・財産・地域功績を得て仕官先を開き、主君の命令を果たして指揮官となり、辺境救援の功績で領主へ進みます。領主になった時点で統治画面が解放されますが、実行できるのは自領の内政・軍備・人事だけです。

統治対象は `jurisdiction（管轄範囲）` で管理します。同じ統治画面が、所領、官職、主君からの期限付き委任、中央の禁止令に応じて段階的に拡張されます。領主が全国政策へ関与するときは直接実行ではなく建議となり、採用されても実施主体は主君と中央政府です。独立後は別画面へ切り替えず、同じ統治画面の対象が新国家全体へ広がります。

序盤から領主就任までの最小プレイループは次のとおりです。

1. 個人マップで「探索」し、発見済みの近隣村へ「移動」して入る
2. 村の酒場（町以上ではギルド）で依頼を受け、酒場で仲間を集めてパーティーを編成する
3. 依頼を達成し、受注した窓口へ報告して功績を得る
4. 使節の注目、偶発的な救命、武術大会、人物紹介などの経路から従士として仕官する
5. 主君の討伐命令を果たし、騎士・部隊長として部隊指揮権を得る
6. 委任された軍務だけで辺境救援を成功させる
7. 男爵・城主となり、同じ統治画面で自領経営を始める
8. 忠誠、建議、加増、独立の道を選ぶ

画面左端の情報欄に「次にすること」と日付・資源をまとめ、この中で現在必要な一手を常に表示します。通常表示は決定・理由・予測・危険を優先し、地図モード、縮尺、統治オーバーレイ、詳細アウトライナーは「専門台帳」で開きます。

## 実装範囲

- 平民・浪人・傭兵、従士・下級兵、騎士・部隊長、城将・代官、男爵・城主、伯爵・地方領主、侯爵・辺境領主、公爵・地方大勢力、宰相・大元帥・摂政、国王・皇帝の10段階
- 帝国、共和国、都市国家、神権国家、遊牧国家、部族連合、軍事政権、魔導国家、海洋国家、連邦の国家形態別称号。独立時に国家形態を選び、その最高位称号をプレイヤーへ付与
- 昇進で離れた部隊・城・地方の日常実務を後任AIへ委任し、人選、方針、裁量、成長、重大事項の上申を保存
- 武勲、政績、町起点で地方間を減衰伝搬する地域別名声、主君の信頼、家臣支持、領民支持、畏怖、正統性、野心を分離した人物状態
- 村の酒場／町以上のギルドでの受注、酒場でのパーティー編成、依頼達成、報告、報酬までを分離した序盤ループ
- 地域ごとの汎用酒場候補とは別に、固定ID・専用立ち絵・経歴・会話・探索能力を持つ固有人物の加入枠
- 固有人物の立ち絵は [固有人物・立ち絵生成ルール](./CHARACTER_ART_GENERATION_RULES.md) に従い、作品共通のアニメ作風を保ったまま顔型・目鼻・眉・表情を既存人物から差別化
- ギルド功績、偶発的な要人救命、武術大会三勝、有力者の紹介という複数の士官経路
- 所領・官職・期限付き委任・対象地域・君主権・禁止令を同時に検証する共有 `jurisdiction` 認可
- 領主就任時に解放され、自領命令、国家政策への建議、独立後の国家命令を同じ場所へ段階追加する統治画面
- UI非表示だけでなく、既存の政策・施設・人事・軍事・外交更新APIでも権限外処理を拒否する認可境界
- EU4系グランドストラテジーを参照した、左端の情報・資源・コマンド欄、中央地図、右側アウトライナー
- 新しい人物を作成するたびに、固有シードから地形・河川・資源・地方・国家領域・首都を生成する世界
- 正方形地形区画を連結した地方へまとめ、複数の行政地域の集合として国家を構成。各地域は人口、中心集落、王都総督・地方伯・辺境伯の役職、領主、現在の支配勢力を持つ
- 城・都市・町・複数の村を結ぶ地方街道網と、人口に応じて村から町、町から都市へ成長する保存可能な集落発展。地域は他国へ移譲されて国境線を変えたり、独立勢力になったりできる
- 世界全体の生成後は現在地の地方レベルへ自動拡大し、世界全図は確認用、地方拡大図は通常プレイ用として切り替える
- 残り移動力と地方の地形負荷を使い、地図上の隣接地方だけを選べる一地方ずつの移動。「進む」を押すと所要時間と移動力を小ウィンドウで確認し、実行後は世界全図で経路・探索隊・進捗をアニメーション表示して、保存可能な世界時計と夜明け・昼・夕暮れ・夜の地図色調が進行
- 地図上の城・村・砦と、発見済みの洞窟・森・泉をクリックして「情報を見る」「ここへ移動する」を選択し、到着した村・探索地へ入る地点アクション
- 地方内では左パネルの「地方内行動」から「探索」で新地点、空振り、モンスター、野草・素材を発見し、「移動」で発見済みかつ現在地に隣接する場所だけを移動
- 個人マップのモンスター遭遇を、既存の参陣者選択、陣形、初期配置、兵站、戦術戦闘、戦果確認へ接続
- 盟約王国から集権後危機までの7国家段階、段階ごとの解禁条件・必須改革・政治的障壁・維持費・地方反応・立て直し経路
- 17権限分野を内部に維持したまま、通常画面では財政、法・治安、人口・土地、軍事、官僚・規格の5国家級改革系統へ集約する改革運用
- 地形から集落・交易路・地方勢力・過去の危機・妥協・特権・現在障壁までを組み立てる生成国家シナリオ
- 世界縮尺の黒潮回廊を遊弋する超規格外生物「リヴァイアサン」と、現在推定域・接近兆候・航路および沿岸国家への戦略的影響
- 外縁に配置したデッドランド冥府・グレート帝国・アバンヘルン連盟の3大国と、世界全域からエルドリア大陸へ戻る縮尺切替
- 国家タイル外周をそのまま海岸線にしたデフォルメ世界地図と、手描きの海・陸地テクスチャ、半透明の政治・州境オーバーレイ
- 余剰動員・交通統合・行政到達・自然国境から巨大国家の成立指数と構造的限界を算出する大国基盤モデル
- 太い国境と細い領域境界、森林・平原・丘陵・山岳・高原・湿地・海岸・荒地、等高線と地形記号を重ねた地勢図
- 地方間の初回移動だけ、街道を優先する「道順」（初期選択）と地形を横断する「最短経路」から既定値を選ぶ。2回目以降は保存した既定値で移動し、変更はバックメニューのシステム欄から行う。道順は時間・補給効率がよく遭遇率6%で弱い魔物が中心、最短経路は保存食3と追加移動力を消費し遭遇率38%で強敵が中心。予告線と移動アニメーションは同じ地形区画列を使用
- 直線的な三角分割を避けた曲線タイルと、クリックした領域の気候・移動・防衛・資源・リスクを示す小ウィンドウ
- 生成世界と分離した原案資料として、バックメニューの設定集からNotion原案の異種族と超規格外生物を参照可能（未詳設定は未詳のまま表示）
- 表画面の主導線を「世界」「人物」の順にし、生成国家・地方・拠点・自然国境比率をまとめた世界統計、キャラクター辞典、称号体系、音響、遊び方をバックメニューへ集約
- 河川沿い、山稜・分水界、湿地帯、気候地形境界を領土拡張の障壁として優先し、人為国境線の採用比率を抑える国家生成

## 起動

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

```powershell
python -m http.server 4180
```

ブラウザで `http://127.0.0.1:4180/` を開いてください。

## 検証

```powershell
npm run check
```
