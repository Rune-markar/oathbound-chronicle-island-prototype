# 誓界記 — 大陸グランドストラテジー

エルドリア大陸のセレナ王国を中心に、世界・国家・都市圏・村々の四つの縮尺を扱うブラウザ向け戦略ゲーム試作です。食料など単独資源の増減を目的にせず、国境関税、隊商差押え、道路規格、軍情報、派閥要求といった表面的事象から、その背後の制度・外交・兵站を解決します。

## ゲームの目的と動線

プレイヤーはセレナ王として、三州の金・食料・治安・民心を維持しながら「灰冠峠の国境危機」を収束させます。今回の主目標は、国境通行権の確保、三州の道路規格統一、敵守備隊情報の確定という三つの条件で進捗を判定します。

毎月の操作は次の四段階です。

1. 季節の初めだけ、評定で今季の方針を一つ選ぶ
2. 解決したい課題と命令を選び、担当武将を割り当てる
3. 今月の計画で費用と翌月予測を確認し、「月を終える」で確定する
4. 都市事件に対応し、月次報告から次の命令を決める

画面上部の「次にすること」は、この中で現在必要な一手を常に表示します。世界地図、各都市の詳細台帳、外交・軍事・人材画面は判断材料であり、最初からすべてを確認する必要はありません。

## 実装範囲

- EU4系グランドストラテジーを参照した、上部資源バー・左側国家画面・中央地図・右側アウトライナー
- 城郭を戦略拠点として各城の兵数・防備、東部国境軍、ヴァルカ守備軍、灰冠峠の戦線、進軍・補給街道を重ねる戦略地図
- 政治・地形・外交・補給・不穏に加え、実効支配・徴税・軍事・司法・人口把握・情報精度・行政負荷・通信時間・地方勢力・歴史的不満・忠誠・制度統一を切り替える地図モードと、世界・国家・都市圏・村々の表示縮尺（初期表示は国家戦域）
- 世界圏の10国家を構成する62大領域・186小領域タイル、セレナ王国の3州・6村、灰冠峠・銀脈河・大陸公路
- 外縁に配置したデッドランド冥府・グレート帝国・アバンヘルン連盟の3大国と、世界全域からエルドリア大陸へ戻る縮尺切替
- 国家タイル外周をそのまま海岸線にしたデフォルメ世界地図と、手描きの海・陸地テクスチャ、半透明の政治・州境オーバーレイ
- 余剰動員・交通統合・行政到達・自然国境から巨大国家の成立指数と構造的限界を算出する大国基盤モデル
- 太い国境と細い領域境界、森林・平原・丘陵・山岳・高原・湿地・海岸・荒地、等高線と地形記号を重ねた地勢図
- 直線的な三角分割を避けた曲線タイルと、クリックした領域の気候・移動・防衛・資源・リスクを示す小ウィンドウ
- Notion原案の15異種族・10国家を相互参照できる世界台帳（未詳設定は未詳のまま表示）
- 世界台帳の統計表示（人口・領域・都市化率、種族・言語・宗教の構成比、5分野から算出する資源力）
- 四半期ごとの評定と、富国・国境防衛・和議・均衡から選ぶ季節方針
- 日次速度操作を使わず、予約した命令を「月を終える」で生産・消費・戦争・事件まで一括解決する月次ターン
- Web Audioで生成する中世調BGMと、操作・決定・警告・月次・都市事件・戦争・講和の効果音（上部の音響ボタンでON/OFF）
- 統率・武力・知力・政治・魅力、忠誠、意欲、功績、特性、所在地を持つ武将制
- 武将を担当に任命し、能力と都市状況から成果幅を予測する内政・外交・軍事・人材任務
- 世界地図・都市ナビ・アウトライナーから開ける専用都市画面（概要、人口、経済・政策、統治委任、施設、派閥、歴史、報告）
- 人口・村落構成・農業・商業・治安・政策・太守から算出する都市収入、食料、徴募回復と翌月予測
- 農地・市場・道路・穀倉・兵舎・役所の建設、6分野の都市政策、農民・商人・地主・軍人の派閥反応
- 統治力4を基準とする命令予約・取消と、最大2点の強行命令、費用・担当人物の予約表示
- 直轄と太守委任、戸籍把握、州郡化、行政到達、州庫留保を扱う拡大型の内政自動化
- 三州 × 17分野の権限保有者を法的権限と実務権限に分け、成立事件・取得年・正統性・慣習定着・地域支持・執行力まで保存する権限台帳
- 情報・行政・財政・強制・インフラ・規格化の六能力と、地方勢力が処理している仕事を引き受ける中央行政能力・行政負荷
- 法的権限、情報、行政、強制、地域服従、交通通信、制度浸透のボトルネックから求める分野別実効支配と、結果指標としての中央集権度
- 可視化、標準化、制度構築、権力移管、反動、定着を進む権限改革と、排除・懐柔・吸収・準備不足の強行移管
- 過去の政治的妥協を理由・権利・義務付きで残す歴史的特権と、改革後に世代継承・減衰する歴史的不満
- 世界状態を先に計算し、反乱・生存・統治断裂・財政軍事の圧力から事件を顕在化させる因果的歴史シミュレーション
- 重要変化を原因・成立条件・結果付きで保存するイベントストアと因果DAG、地域別の時代区分へ圧縮する年代記コンパイラ
- `World Truth / Historical Record / Public Belief` を分離した歴史認識と、過去の特権を現在の改革制約へ変換する制度的負債
- 名目総量とは別に、中央へ送れる金・兵糧と動員可能兵を算出し、併合直後の国力化を抑制
- 不作・洪水・盗賊・疫病・難民・汚職・商人流出・農民一揆の選択事件、歳入と6分類支出を円グラフで比較できる月次・年次の国家財政報告
- 各都市の都市金・兵糧・人口・兵・徴募人口・施設稼働・派閥支持を合算する国力台帳（抽象的な行政／外交／軍事ポイントは不使用）
- Notion原案の「仕官」「勧誘」「登用」、協定打診、経済支援、開戦正当性
- 「国境通行権」「峠共同管理」「政権屈服」から政治目的を先に選ぶ宣戦布告と、敵意の高まりから始まる防衛戦争
- 戦力比だけでなく、正当性、地形・街道、補給、情報確度、周辺国介入、攻勢限界を説明し、攻撃側・防衛側で異なる行動を選ぶ戦争AI
- 軍団長・副将・相性・陣形・道路稼働・駐屯容量を反映する国境軍編成
- 防衛線保持・補給遮断・要地攻略・城砦攻囲・機動反撃・焦土遅滞から立場に応じて選ぶ月次作戦と、兵員損失、施設破壊、避難民、住民被害の累積
- 停戦・当初目的・軍事占領から戦況に応じて選ぶ終戦条件と、戦役結果を残す戦史
- 自治保障・漸進統合・強制同化・直接軍政・復興優先、駐屯兵、抵抗運動、占領費・収入、撤兵を扱う戦後統治
- v8ローカル保存と継続する因果年代記（v6・v7保存は不足項目を補完して移行）

## 起動

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

```powershell
python -m http.server 4180
```

ブラウザで `http://127.0.0.1:4180/` を開いてください。

## 検証

```powershell
npm run check
```

国家進行は `src/monthly-simulation.js`、公開入口は `src/simulation.js`、都市・武将の派生計算は `src/realm-model.js`、州郡統治は `src/administration-model.js`、履歴イベント・圧力・因果グラフ・年代記編纂は `src/history-model.js`、世界統計は `src/world-statistics.js`、作戦・講和・占領政策の定義は `src/war-system.js`、相手の戦争判断は `src/war-ai.js`、音響生成は `src/audio.js`、画面制御は `src/app.js` に分けています。外部ライブラリ、外部音源、外部通信は使用しません。
