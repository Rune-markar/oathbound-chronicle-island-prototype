# 2026-08-16 新規開始・立身進行 実プレイレビュー

## 実施条件

- 対象: `main` の犯罪プレー実装後（開始時 `8c6b737`、修正は本記録と同じ変更単位）
- ブラウザ: Codex In-app Browser（Chromium系）
- 起動: `python -m http.server 4191`、`http://127.0.0.1:4191/`
- プレイヤー: `実地検証者`、人間、没落貴族、戦士
- 操作方針: 保存データの直接編集や開発者メニューを使わず、表示された通常UIだけを操作

## 実際に通った手順

1. 「女神の世界へ」を選択する。
2. 女神の3会話を待ち、名前・種族・出自・適性・能力値を確認して「この魂を受け入れる」を押す。
3. 世界生成100%と降下演出を待つ。開始地はラグナ石原地方だった。
4. 地図上のラグナ柳原町を選び「ここへ移動する」。ゲーム内10時間の移動演出後、「町へ入る」。
5. 「村人との交流」→「会話」を6回行い、町との関係を0から6へ上げる。
6. 「酒場」→「紹介を頼む」で、森の連合評議会への仕官招請を得る。
7. 人物詳細の「仕官先を選ぶ」で森の連合国を選び、従士となる。
8. 「主君の討伐命令を果たす」で部隊長となる。
9. 後任・方針・裁量を確認し「辺境救援軍を指揮する」で城主となる。
10. 「領内基盤を固める」を2回実行する。家臣支持60、政績24となり独立条件を満たす。
11. 国家形態に帝国を選び「辺境に新国家を建てる」。皇帝（独立君主）へ到達する。
12. 「統治」を開き、国家命令を実行可能な画面まで表示する。

新規開始から独立君主の表示までは、演出待ちと地方移動待ちを含めて実操作約3分だった。現行の通常UIで到達できる立身上限は独立君主である。

## 到達結果と実装上限

到達自体は可能だった。ただし、設計用の10位階すべてを順番に遊べるわけではない。通常UIで実際に状態として通過したのは次の6候補のうち、任意の伯爵を省いた5段階である。

`平民・浪人・傭兵 → 従士・下級兵 → 騎士・部隊長 → 男爵・城主 → （任意: 伯爵・地方領主） → 国王・皇帝`

城将・代官、侯爵・辺境領主、公爵・地方大勢力、宰相・大元帥・摂政には通常UIの昇進アクションがない。今回、画面上の進行表示は実際に通過できる6段階へ修正し、10位階は将来拡張を含む設計カタログとして文書に残した。

## 実プレイで確認した不具合と修正

1. 保存がない新規オリジンでも「年代記を開く」が表示され、15秒待つだけで仮の初期状態を自動保存して女神導入を迂回できた。
   - 有効なv10保存がある場合だけ「年代記を開く」を表示する。
   - 人物作成完了前の仮状態は自動保存しない。
   - 世界生成完了時は画面を閉じる前に即時保存する。
2. ラグナ南境地方で城主・皇帝になったのに、人物・統治画面が旧固定世界の「城塞市オルタ」を所領として表示した。
   - 内部の固定行政対象は互換のため保持し、所領へ生成地域IDを併記する。
   - 人物、統治、アウトライナーでは実際の生成地域名を表示する。
3. 人物詳細を開くと、背面の同じキャリア操作と詳細内の操作が両方フォーカス可能で、同名ボタンが二つ存在した。
   - 詳細表示中は背面ワークスペースを `inert` にする。
4. 依頼完了後、受注元とは別の集落でも報告できた。
   - `acceptedVillageId` と現在の集落を照合し、受注元だけで報告可能にする。
5. 集落会話ダイアログに初期フォーカス、Esc終了、起点へのフォーカス復帰がなかった。
   - 開始時に終了ボタンへフォーカスし、Escで閉じて起点へ戻す。
6. 外国暗殺で死刑相当となっても、モデル上のゲーム終了後に通常操作を続けられた。
   - 保存されるゲームオーバー画面を表示し、背面のゲーム操作を `inert` にする。新しい人物で始める操作だけを提示する。
7. 開始画面のビルド番号が犯罪プレー実装前の `f37aec7` のままだった。
   - 本修正の実装コミットへ更新する。
8. マニュアルだけ保存形式をv9と記載していた。
   - 現行のv10へ修正する。

## 良かった点

- 女神導入、世界生成、地方地図、地点移動、集落、人物詳細、統治へ画面の流れは切れず、独立君主まで通常UIで到達できた。
- 地点移動は経路・所要時間・世界時計が視覚化され、到着後にだけ「町へ入る」が現れる。
- 集落の施設、序盤依頼盤、士官への4経路、犯罪カードが同じ現在地に結びついている。
- 犯罪カードは対象、管轄、準備、見込報酬、最大刑罰を実画面で確認できた。

## 改善提案・未実装事項

優先度高:

- 「主君の討伐命令」「辺境救援軍」は現在ボタン一回で必ず成功する。準備、戦術戦闘、損耗、失敗、撤退を通常ループへ接続する。
- 設計上の城将・代官、侯爵、 公爵、摂政を本当に遊べる昇進条件・権限・事件として追加する。追加までは10段階を「実装済み」と表現しない。
- 生成世界の第二所領は、現在地の固定別名ではなく、実際に選んだ別の生成地域を加増対象にする。

優先度中:

- 紹介経路は同じ「会話」を6回繰り返すだけで開く。会話内容、相手、依頼や地域貢献を組み合わせた関係獲得へ変える。
- 初回女神会話と世界生成は雰囲気が良いが、再プレイ用に既読時だけ「魂の選択へ進む」を用意する。
- 第二所領の必要値（主君信頼62・政績10）を押下前に表示する。
