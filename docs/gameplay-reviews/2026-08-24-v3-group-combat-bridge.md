# 2026-08-24 V3軍務・集団戦接続 実プレイレビュー

## 目的

V3の1マス移動を入口にしながら、部隊・軍勢による戦いだけを既存の戦闘前編成、兵站、20×14戦術盤、戦果画面へ渡す。V2セーブは使わず、勝敗と損耗をV3の作戦履歴へ戻す。

## 接続した流れ

1. 集落から7詳細マス以内で「軍務」を受ける。
2. 動的国境を含む現在の所有国、地方、地形から自軍・敵軍と到達可能な7〜12マス先の作戦地点を決める。
3. 作戦地点を13×11フィールドと概算世界地図へ表示し、プレイヤーが1マスずつ歩く。
4. 到着時だけ集団戦の確認を出し、V3主人公と現地将校を参陣候補として既存の戦闘前編成へ渡す。
5. 参陣人物、陣形、初期配置、兵站を選び、既存の20×14戦術盤で戦う。
6. 戦果画面からV3へ戻り、勝敗、両軍損耗、軍功、経験、銀貨、作戦履歴を保存する。

編成画面から戻った場合は作戦を失わず、同じ地点から再開する。ページを戻った場合や再読込した場合も、一時ブリッジとV3セーブの状態を照合して再開する。決着後は一時ブリッジを削除し、同じ戦果を二重反映しない。
