# 誓界記 — 小島国プロトタイプ

企画書の「同じ世界を国家として治め、一人として生きる」と「理解した摩擦を制度へ圧縮する」を、一件の徴発危機で検証するブラウザ向け試作です。

- 非公開リポジトリ: <https://github.com/Rune-markar/oathbound-chronicle-island-prototype>
- 更新履歴: <https://github.com/Rune-markar/oathbound-chronicle-island-prototype/blob/main/CHANGELOG.md>

## 今回のスコープ

- 1国家: セレナ島侯国
- 3都市: 王都セレネ、港都ネレイア、鐘楼市オルタ
- 6村: 各都市圏に2村
- 1危機: 8日以内に北方備蓄48樽を届ける
- 3縮尺: 島国、都市群、村々
- 3つの誓約案と、調査・対話・台帳・輸送整備による異なる解決経路
- 一人物の現在地、都市・村間の移動時間、現地にいる場合だけ可能な行動
- 村の在庫、輸送損失、信頼、生活負担、誓債を同じ状態として共有
- 必要量48樽で自動停止する輸送と、冬越し線を守る保護誓約
- ローカル保存と複数の結末

## 起動

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

```powershell
python -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開いてください。

## 検証

```powershell
npm run check
```

ゲームロジックは `src/simulation.js`、画面制御は `src/app.js` に分離しています。今回の段階では外部ライブラリ・外部画像・通信を使用しません。

## 更新履歴の管理

変更点は、この非公開リポジトリの `CHANGELOG.md` を正本として管理します。更新時は新しい日付・バージョンを先頭へ追記し、検証後に `main` へpushしてください。
