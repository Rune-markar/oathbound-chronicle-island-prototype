# 生成国家間の自律戦争 実装・検証記録

## 確認対象

生成国家の地政判断から実際のAI対AI戦争が始まり、攻撃・防衛理論、実在国境、前線、兵站、損耗、攻城、講和、地域支配変更、見聞による表示制限まで同じ月次ループで成立するかを確認した。

## 実装確認

- `limited_war` による二国間関係の非戦争から戦争への遷移だけを開戦起点にした。
- 現在の地域支配から実在する隣接地方を抽出し、人口・首都・地域中枢・移動負荷から主目標と最大二正面を選んだ。
- 攻撃側四種、防衛側三種のドクトリンと、野戦・攻城の立場別行動を追加した。
- 戦力、補給、士気、累計損失、正面進捗をコンパクトな `worldWars` 台帳へ保存した。
- AI勝利時は `regionalDomains` の実地方一つを限定割譲し、終戦後12か月休戦へ移した。
- プレイヤー支配国を含む場合は判断待ちにし、自動講和・割譲を止めた。
- 世界情勢では、噂または現場で戦争イベントを知った場合だけ攻守ドクトリンと戦況を表示した。

## 自動確認

焦点テストでは、実在国境、一〜二正面、決定性、攻守ドクトリン、月次行動、補給消費、双方損失、攻城、限定割譲、休戦、プレイヤー判断保留、旧保存補完、表示名解決を確認した。さらに地政危機を三か月継続させた通常の月次入口からAI対AI戦争を開始し、その後24か月を進め、一国家の二重参戦がないこと、戦争が終結戦史へ移ること、イベントIDが重複しないことを確認した。

既存の生成世界、地政、地域支配、プレイヤー戦役、世界見聞、地図UIの焦点回帰も併せて実行する。

最終 `npm run check` はソース64ファイルの構文検査に成功し、555/555テスト成功、失敗・キャンセル・スキップ0だった。`git diff --check` も成功した。

表示確認用に通常と同じ公開APIでサレム峰国対アステル坑道国の戦争を作り、開戦、動員、野戦の三件を「国境商人の戦況報告」として見聞台帳へ保存した。通常の再開ボタンから入り、`世界 → 世界情勢` の「把握済みの列国戦争」で、当事国、野戦段階、食料・生産地方の確保、アステル中央地方、回廊戦争、城砦網防衛、双方戦力・補給・損失、正面進捗3%、補給線遮断／防衛線強化を確認した。

## 現在の境界

AI対AI戦争そのものは生成地方を正本に実装した。ただし、プレイヤー戦役とAI戦争はまだ別台帳であり、旧固定戦域盤と固定都市占領も残る。三正面以上、進行中戦争へのプレイヤー介入、首都陥落・国家滅亡・全面併合は今回の範囲外である。
