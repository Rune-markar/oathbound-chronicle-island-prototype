# スマホ縦向き本編の固定画面設計

## 状態

- 仕様決定日：2026-08-20
- 対象：幅980px以下の縦向きスマートフォン・タブレット
- 状態：実装・検証済み
- 後継元：[スマホ横向き本編の固定画面設計](./2026-08-16-mobile-game-shell-design.md)

## 背景

横向きスマートフォンでは、地図、人物、現在目標、日時、主要操作、詳細本文を短い高さへ同時に収めるため、文字と操作が小さくなりやすい。横向きの固定三層を拡大しても、詳細ドロワーと戦術画面では縦の可視領域が不足した。

本変更ではスマートフォン操作を縦向き専用とし、PC横長レイアウトを維持したまま、縦方向へ常設情報と操作を分離する。

## 目的

- 縦向きで人物、日時、現在目標、地図、主要6操作を同時に確認できる。
- 本文12px以上、主要操作44px以上を基準にする。
- 詳細を開いても地図の一部と現在の画面位置を把握できる。
- 回転やドロワー開閉で地図のパン、縮尺、選択地点を失わない。
- 保存形式、解放条件、権限、ゲームルール、PC操作を変えない。

## 画面構造

### 上部二段バー

- 合計94pxを基準とする。
- 1段目44pxに人物入口と年月・時刻を置く。
- 2段目50pxに現在目標を横幅いっぱいで置き、最大二行で表示する。
- 現在目標は既存の文脈ショートカットとして動作する。

### 中央地図

- 上部94pxと下部ナビを除く `minmax(0, 1fr)` を使用する。
- パン、タッチスワイプ、縮尺、地点選択、移動確認を維持する。
- 凡例は初期状態で閉じ、必要時だけ表示する。

### 下部ナビ

- 64pxと端末の下部安全領域を確保する。
- `世界 / 人物 / 統治 / 国制 / 評定 / その他` の順序を固定する。
- 各項目はアイコンと12px以上の名称を持ち、未解放項目は位置を保ったまま非活性にする。

### 詳細下部シート

- 横幅いっぱいを使い、上端を `max(上部バー + 80px, 34dvh)` とする。
- 上側へ地図を残し、本文だけを内部スクロールさせる。
- 閉じるボタンは44px四方とし、背景タップとEscapeでも閉じられる。
- 開いたときは閉じるボタン、閉じたときは起点ボタンへフォーカスを移す。

## 横向き開始ゲート

- 幅980px以下の横向き画面では本編を圧縮表示せず、「縦画面でゲームを開始」を表示する。
- 操作時は全画面化してから `screen.orientation.lock("portrait")` を要求する。
- 固定APIが使えない場合は、端末を縦向きにする案内をライブ領域へ表示する。
- この操作で全画面化した後に固定が失敗した場合だけ全画面を解除する。
- 1280px級のPC横長表示にはゲートを適用しない。

## 横幅依存画面

- 開始画面と開発者メニューは一列にする。
- 女神界の人物設定は横幅いっぱいの内部スクロール領域とし、立ち絵を背景へ退避する。
- 交易商品は名称、価格、数量、操作を一列へ積む。
- 戦術盤は盤面を内部スクロールし、ユニット詳細を盤面下側の内部スクロールシートにする。
- 戦闘準備と探索は画面全体の縦スクロールを許可し、決定操作へ到達できることを優先する。

## 状態と互換性

- コンパクト判定は `(max-width: 980px) and (orientation: portrait)` を正本とする。
- 既存の `data-panel`、`data-shortcut-tab`、ドロワー状態、地図状態を再利用する。
- UI切替だけでは地図を再生成しない。
- 保存スキーマとゲーム状態は変更しない。
