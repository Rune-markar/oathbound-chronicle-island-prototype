# 2026-09-02 V3目的駆動型フィールド人物・敵レビュー

## 結論

既定入口 `index.html` のGeneration V3では、人物・敵を詳細マスごとの確率抽選で生成しない。`src/v3-field-system.js` が概算世界と当日の国家状態から少数の `ActorPlan` を先に作り、プレイヤーの視界に入った座標だけを観測可能な人物として表示する。

## 実装した因果

- 行商は、国家AIの直近の「食料確保」決定、国家食料安全度、集落人口、概算区画の食料収量、農村・漁港機能、戦争状態、実在街道を評価する。国境越えの食料輸入、国内補給、戦時糧秣、平時の集落間流通のいずれかが成立した時だけ生成する。
- 行商人は国家行動ID、品目、出発集落、到着集落、街道ID、目的、理由を持つ。同じ到着国は一日一隊までとし、その日の街道上の一地点を輸送過程として表示する。
- 集落人物は一集落一名までとし、平時は都市機能を支える仕事、戦時・城塞・国境・迷宮では巡回任務を持つ。
- 野外敵は一地方一体までとし、地方内の生息地と世界現象の危険補正から活動地点を選び、狩り、縄張り、営巣、見張りなどを目的にする。
- 街道盗賊は実在する隊商と低い国家結束または戦争が同時にある場合だけ、その隊商を対象に生成する。新月の霊体は新月の夜に遺跡がある場合だけ生成する。
- 目的ラベルは可視マスのARIA、NPC会話、敵発見ログ、個人戦の敵表示へ渡す。

## 自動検証

`tests/v3-field-system.test.mjs` の二国間小世界で、国家AIが `secure_food` を選び、食料安全度35の国へ穀物を運ぶ「国家の食料輸入」が一隊だけ生成されることを確認した。国家行動、出発地、到着地、街道、品目を追跡でき、全人物・敵の目的が存在し、座標重複がなく、人物・敵密度が総詳細マスの1%未満になる。既存の敵発見、フィールド内個人戦、昼夜で消える遺跡の新月霊体も回帰する。

`npm run check` はソース94ファイルの構文検査と全773テストに成功した。

## 実生成世界と実ブラウザ

固定シード `map-chip-review` の保存済みV3世界を再構築した結果、1,474,560詳細マス、7国家、125集落、64地方に対して日次 `ActorPlan` は195件、密度0.0132%だった。内訳は集落の働き手85、巡回役40、地方敵63、集落間の食料流通7で、座標195件はすべて一意だった。この世界の日付と国家状態では食料輸入は成立せず、輸入分岐は上記の不足国テストで確認した。

- 390×844：13列×11行、可視マス約30×29.73px、横溢れ0、方向操作44×44px、console warning/error 0件。

## 現時点の境界

`ActorPlan` は一日の行動を街道・集落・生息域の一地点として観測する仕組みであり、画面上で一歩ずつ自律移動するアニメーションや、輸入量を国家備蓄へ再加算する物流会計までは行わない。現在の輸送品目は食料系に限定している。次に拡張する場合も、鉱石・薬草・軍需などの国家需要を同じ目的・経路・上限契約へ追加し、マス確率抽選へ戻さない。
