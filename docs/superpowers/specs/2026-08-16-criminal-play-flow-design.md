# 犯罪行動プレイフロー設計

## 目的

犯罪者専用キャリアを増やさず、既存の平民・仕官・領主・君主キャリアで、場所と対象に応じた違法手段を選べるようにする。犯罪の利益だけでなく、地域別手配、人物の拒否・密告、裏社会、刑罰、年代記、権力濫用まで通常プレイへ接続する。

## 基本方針

- 窃盗、強盗、密輸、恐喝、破壊工作、暗殺を一括導入する。
- 各犯罪の実行過程は個別に持ち、事件結果と社会反応だけを共通化する。
- 犯罪機会は市場、街道、国境、人物、道路・砦・施設など具体的な対象から提示する。
- 無差別な住民加害、偽名・変装、詳細な証拠捜査、犯罪組織の縄張り政治は扱わない。
- 正の地域名声と犯罪歴を相殺せず、英雄として知られながら指名手配される状態を許容する。

## 共通結果

犯罪結果は `success_hidden`、`success_exposed`、`failed_escaped`、`captured` の4種類とする。実行前には確率を表示せず、成功見込みと発覚危険を「有利」「互角」「危険」「極めて危険」で示し、想定利益、必要準備、最大刑を併記する。判定は世界シード、ターン、対象、試行番号から再現可能にする。

発覚時の手配熱は窃盗15、密輸20、恐喝25、強盗35、破壊工作45、暗殺70。0〜19を平常、20〜39を警戒、40〜69を指名手配、70〜100を厳戒とする。軽犯罪は対象地域外で2か月犯罪を起こさなければ月5ずつ減衰する。未処理の重大犯罪は40、暗殺は70を下限とし、刑罰、赦免、国外亡命・保護でのみ追跡状態を変更する。

## 犯罪別フロー

- 窃盗：店舗・倉庫から対象品を選び即時判定する。成功品へ盗品属性を付ける。
- 強盗：街道輸送隊を威圧し、拒絶された場合は既存戦術戦闘へ接続する。
- 密輸：裏社会から禁制品を受領し、国境検問を越えて指定地域へ届ける。
- 恐喝：商人・役人へ一時金または継続上納を要求し、反復で密告・報復を強める。
- 破壊工作：道路、砦、集落施設を下見・準備・実行し、実際の稼働状態を低下させる。
- 暗殺：標的可能と明示された生成人物・地方領主だけを対象に、情報・接近・実行者を準備する。

## 裏社会・共犯・処罰

酒場で財産1を使う「裏口の噂を探る」から、故買人、密輸人、仲介人を地域単位で解禁する。盗品は通常価格の40%で換金し、信用20以上で潜伏先を利用できる。共犯者は犯罪種別、対象、関係、契約、恐怖、本人の許容範囲から承諾を決め、拒否、密告、離反、共犯化を記録する。

軽犯罪の拘束は不法利益没収、罰金、1か月拘禁。重大犯罪は没収、地位・信頼低下、3〜12か月拘禁。暗殺の拘束・有罪は処刑・ゲーム終了とする。君主の自国内犯罪は逮捕せず、権力濫用として正統性、領民支持、家臣支持、反乱圧力、因果年代記へ返す。国外では相手国の手配を受ける。

## UI

既存の対象操作へ色分けした「非合法」区画を追加する。キャリア画面には地域別手配、未処理刑、裏社会接触先、最近の犯罪事件を表示する。手配中は操作不能にせず、施設拒否、検問、潜伏、逃走へ選択肢を置き換える。

## 受入条件

- 6犯罪がそれぞれ異なる実行フローと実世界効果を持つ。
- 地域別手配、軽犯罪の減衰、重大犯罪の下限、処罰、赦免・亡命が保存復元できる。
- 共犯者の拒否・密告・離反と裏社会信用が通常の人物・集落導線へ接続される。
- 正の地域名声が犯罪で消えず、君主犯罪は権力濫用へ変換される。
- 個人年代記には全事件、世界年代記には発覚した重大犯罪と権力濫用が残る。
