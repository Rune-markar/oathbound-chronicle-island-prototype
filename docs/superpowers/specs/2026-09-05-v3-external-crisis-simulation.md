# Generation V3 外部危機シミュレーション仕様

## 目的

平和・戦争だけで推移していた生成世界へ、災害、飢饉、魔族襲撃を因果のある外部圧力として加える。危機はプレイヤーの近くへ突然生成する敵やイベントではなく、地方単位で月次進行する概算世界の状態を正本とする。詳細フィールドは、その状態を観測できる範囲へシンボルとして投影する。

## 危機の種類と原因

| 種類 | 主な入力 | 主な影響 |
|---|---|---|
| 大規模洪水 | 洪水危険、土壌水分、河川・三角州・湿地、季節的増水 | 食料・結束・備蓄、人口、地方施設、穀物 |
| 広域山火事 | 森林、少雨、高温、乾期 | 食料・結束・備蓄、人口、地方施設、穀物・木材 |
| 地方飢饉 | 国家食料安全度、地方生産力、戦争、同地方の自然災害 | 食料・結束・備蓄、人口、穀物 |
| 魔族襲撃 | 遺跡・洞窟・火山等、結束・防衛、戦争、魔力潮 | 食料・結束・防衛・主権、人口、地方施設、鉄・薬草 |

各入力は0〜100の地方別圧力へ正規化する。毎月、前月値74%と当月目標26%を合成し、一時的な乱数判定ではなく蓄積と減衰を表現する。季節位相と魔力潮は世界シード、地方、種別、年月から決定論的に求める。

## 発生と終息

- 圧力52以上で新規発生候補になる。
- 活動中は `outbreak`、`active`、`emergency`、`recovering` の段階と危機度1〜5を持つ。
- 同一地方・同一種別は重複させず、一地方2件、全世界12件を上限とする。
- 洪水・山火事は12か月、魔族襲撃は18か月、飢饉は24か月を最長期間とし、その後は回復局面へ移る。
- 圧力低下または最長期間後の回復局面を経て終息し、同じ地方・種別へ6か月の再発猶予を置く。
- 終息履歴120件、出来事240件を上限として、長期セーブを無制限に増大させない。

## 世界への影響

危機の危機度に応じて、所有国家の五条件を月次で減少させ、`stateReason`を更新する。同じ月に地方内集落人口を減少させ、地域施設の状態を損耗させる。一国家へ複数危機が重なった場合の条件損失は一項目あたり月6点を上限とし、人口損失と施設損耗にも月次上限を置く。

市場では戦時補正と外部危機補正を合成する。自然災害・飢饉は穀物、山火事は木材、魔族襲撃は鉄・薬草の価格上昇と在庫低下へ波及する。表示用の説明と実際の売買計算は同じ関数を参照する。

## 表示と詳細投影

世界地図の現象レイヤーは、従来の気象域に加えて危機の発生元となる概算区画へ危機シンボルを描く。世界現象パネル、現在地、国家詳細、年代記は同じ活動中危機を参照する。

詳細フィールドでは、現在地方に活動中の危機がある場合だけ、13×11視界内の通行可能な非集落マスへ一件ずつシンボルを置く。位置は世界シード、危機ID、日、座標から決定し、観測範囲が変われば再投影する。シンボルは危機の存在、原因、危機度を伝える観測対象であり、敵へ変換せず、接触しても戦闘を開始しない。取得済み・会話済み座標の差分にも消されない。

## 保存と互換

正本は `state.worldSimulation.externalCrises` とし、版、地方別圧力、活動中危機、終息履歴、出来事、最終進行年月を保存する。月次の発生・深刻化・回復・終息は出来事として保持し、重量の大きい地図スナップショットを危機発生ごとに複製しない。年次・国境変動スナップショットには過去年代の地図表示に必要な危機項目だけを保存する。「1か月進める」を反復しても過去の「現在」スナップショットは一件を超えて蓄積しない。world-simulation v2はv3へ移行し、外部危機未設定を `null` として受け入れ、現行ランタイムと年月から初期化する。V3保存全体の版はV6を維持する。

## 受入条件

- 同じ世界シード、状態、年月から同じ圧力、危機、影響、シンボル位置になる。
- 50年固定史で洪水、山火事、飢饉、魔族襲撃の開始と終息を確認できる。
- 危機が国家条件、集落人口、地方施設、市場へ作用する。
- プレイヤー地方の危機は詳細視界へシンボルとして出るが、敵遭遇へ変わらない。
- 世界地図と詳細フィールドをPC・390×844の通常UIで確認し、横溢れ、主要操作寸法、コンソール警告・エラーを検査する。

## 対象外

避難、救援、討伐、復旧をプレイヤーが選択して危機へ介入するクエスト、危機勢力の部隊単位移動、延焼・氾濫を詳細マスごとに計算する流体・セルオートマトンは今回の対象外とする。
