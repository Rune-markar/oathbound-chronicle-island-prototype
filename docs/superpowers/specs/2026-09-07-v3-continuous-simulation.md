# V3人物史・統治・世界終局と市場国家フィードバック

## 目的

index.htmlから新規開始し、個人の仕事、探索、交易、軍務を同じ人物の功績として、地方任命、統治、主権、諸国との交渉、制度に基づく二終局、結末後の年代記へつなぐ。

## 正本と境界

- 人物はV3 field.player、生成地域支配はworldSimulation.generatedWorld.regionalDomains、市場はworldSimulation.marketEconomy。
- 進行は任意のfield.campaign v1。現行V6保存を維持し、旧世代と未知の進行版は拒否する。
- 行動結果の世界変更と時間経過はcommitV3Actionで確定する。月次は各月の世界更新後に統治を一回だけ更新する。
- 地政学・環境・文化は既存の生成世界を参照し、民族の固定的な善悪・優劣は定義しない。

## 操作

人物史・統治は通常フィールドから開く。各段階で次の行動、必要な功績、費用、所要時間、政策の利益と代償、実行できない理由を示す。開いた間はフィールドをinertにし、閉じる・Escape・フォーカス循環で操作を戻せる。自動モードは中断する。

## 国家と市場

市場の消費不足と物流を同じ在庫台帳へ記録する。搬入は当月の未充足消費を先に満たし、余分だけ在庫へ加える。国家ごとの穀物備蓄・未充足割合・物流から食料、財政、結束を有界に変え、翌月の国家判断へ戻す。国家詳細は確定済みの月次値であることを表示する。

## 検証

複数シード・二経路・条件不足・失敗後回復・月次一括／逐次一致・同月再処理・保存往復・既存V6・未知版拒否をドメインで検証。通常UIは新規開始からPCと390×844で通しプレイし、操作停止、保存再開、結末後の継続、横溢れとconsoleを確認する。

実際の結果は docs/gameplay-reviews/2026-09-07-v3-continuous-simulation.md に残す。

## 市場から国家へ戻す月次因果

各商品の lastConsumption は当月需要を表し、lastUnmetConsumption は生産・前月在庫・当月の街道補給で満たせなかった量を表す。街道輸送は不足側の未充足分を先に消費へ充て、残りを備蓄へ加える。物流の発地減少と着地の在庫増加・補給時消費の合計は一致する。危機や食料確保政策は月産を変えるが、倉庫容量は平常時の生産適性から計算し、一時的な不作だけで保存済み在庫を切り捨てない。

国家条件への反映は当月市場と物流の確定後、月に一回だけ実行する。穀物未充足率と0.75か月未満の備蓄が食料へ最大-3、穀物未充足が結束へ最大-3、全商品未充足が財政へ最大-2の影響を与える。前月の不足が半分未満となり、備蓄が0.75か月以上へ回復した時は、食料60未満と結束50未満に各+1を与える。食料条件35未満なのに当月需要を満たし1.5か月以上の実備蓄がある場合は、食料を+3して抽象的な飢餓と実在庫の乖離を縮める。各条件は0〜100に制限し、国家理性の五条件を再計算する。通常の余剰備蓄だけで毎月財政や結束を増やす処理は置かない。

lastFeedbackPeriod と nationFeedback を marketEconomy に保存する。保存・描画・同月再処理では追加効果を与えない。国家詳細の marketFeedback は最後に決算した月の集計であり、同月中の売買後在庫とは表示上も区別する。次月の国家判断はこの実需反映後の条件を読む。

国境物流能力は道路状態・重要度に加え、二国の通商関係、外交関係、現在の意思決定プロフィールの開放性を参照する。開放性補正は0.8〜1.2、外交補正は0.55〜1.65、戦時能力は同条件の平時の20%。国内街道には国境補正をかけない。種族名に固定的な取引罰は置かない。食料確保政策は当月の当該国の穀物生産を15%増やし、既存の財政費用と国家判断へ接続する。

境界は概算集落・既存街道の月次集計とし、個人の家計・輸送中の荷車・海上交易・通貨発行までは追跡しない。係数はゲーム内の仮定であり、実世界の因果量を推定したものではない。

## V3人物史のAPIと到達条件

実装は `src/v3-campaign-system.js`。`normalizeV3CampaignState(context, state)` は任意の `field.campaign` を v1 に正規化し、未知の版は拒否する。`getV3CampaignView(context, state, worldSimulation)` は段階・地域条件・数値要件・実行理由付き行動一覧・判断履歴を返す。`performV3CampaignAction(context, state, actionId, { targetId, worldSimulation })` は状態・費用・所要時間・イベントと変更後の `worldSimulation` を持つ ActionResult を返す。`advanceV3CampaignMonth(context, state, worldSimulation, calendar)` は境界月の状態・世界・イベントを返し、同じ月を二度決算しない。

| 段階 | 条件と実際の変更 |
| --- | --- |
| 地方の委託 | 探索12歩、商品3個販売、軍功1、地域実務1回のいずれかと所持金2。実際に到着した集落の地方へ接続する。 |
| 地方総督 | 探索36歩、商品9個販売、軍功3、地域実務3回または商会設立のいずれかと所持金8。委託地方へ戻り、その領有国の下で実在地域の役職に就く。最初の公金は任命国の準備金から最大16を移す。 |
| 自治国家 | 統治2か月・住民支持50・公金12。任官した一地方だけを独立国家にし、元の国家の残余領土は引き継がない。 |
| 帝国 | 現存する生成地方の60%以上、中央集権制度3件、条件を満たした累計12か月の集権危機統治、住民支持45。条件不足では危機の進行を止め、回復後に再開する。 |
| 自治連邦 | 自国を含む存続国家6か国の同意。現存国が6未満なら現存国数。自治制度6件・4分野、自治60、住民支持50、義務不履行1以下。信頼不足や自治撤回で加盟は有効数から外れる。 |

地域実務は一日と引き換えに所持金4を得る。毎月の収入は統治下の集落人口・市場の穀物充足・街道状態・戦争・制度から、費用は地方数・制度・危機から決まる。領土や任命権を失った地域からは徴税せず、現地の仕事と新しい領有国の行政任命から立て直せる。修繕・練兵は実市場の木材・鉄・穀物を購入して消費する。救援は街道または既存航路で接続する余剰市場の穀物4を減らし、空き容量のある地方市場へ同量を運ぶ。供給元や搬入容量がなければ実行できない。

統治移管と軍事圧力は隣接地方、または既存の生成航路の対岸に限る。海路には追加費用と時間を設ける。外交合意は国別の信頼、戦争状態、自治と文化保障を確認する。停戦は既存の世界戦争APIを通し、損耗・終戦記録・講和イベントを残す。毎月の海上商流全体は対象外であり、この航路接続は評議会による輸送・統治行動に限る。

帝国は「帝国布告→リヴァイアサン討伐遠征→女神の統治権受領」、自治連邦は「連邦憲章→生息域協定→女神の統治権拒否」を、それぞれ別の月に確定する。最初の宣言後は別経路へ変更できず、後続の最終行動も現在の領土・同意・制度条件を確認する。討伐遠征には防備65と公金18が必要。最終行動はV3評議会で費用と国家判断を解決する簡略化した終局で、固有ボスの戦術マップや旧版の10階級制を全面移植したものではない。保存した `campaign.ending` は経路IDで、結末後も同じ世界の探索・統治・月次進行を継続する。

## 並行する自動モード改善との接続

地図・台帳の閲覧中は自動モードの進行と入力・スクロールを保持する。人物史・統治を開くと明示的に一時停止し、評議会で確定した行動は同じ共通時計へ反映する。既定の関係地域による危機停止には、旅行先や販路だけでなく現在の自国・実統治地方を含め、他国滞在中でも統治の判断が必要な出来事を見逃さない。失職・領土喪失後は現支配を再確認し、元の任官先を無条件に監視しない。
