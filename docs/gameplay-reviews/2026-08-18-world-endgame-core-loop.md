# 世界終局と中核概念の実プレイ評価

実施日: 2026-08-18
対象: 通常キャリアの独立君主から世界終局まで
環境: Chromium、デスクトップ、横向き844×390

## 結果

超合理世界帝国と多元主義世界連邦を、それぞれ通常の「国制」画面、確認ダイアログ、月進行だけで三段階完走した。両方とも人物・世界年代記へ判断が残り、最後にリヴァイアサン、世界主権、この結末を成立させた具体的制度を示す終局画面が開いた。コンソールエラーと警告は0件だった。

中核概念は成立している。合理化側は実効中央集権95、法・実務100、行政負荷62%という明確な実利を持ち、単なる悪役選択ではない。その代わり、旧権力排除、全国一律改革、記録封印を経て、最後の拒否権まで女神へ委ねる。多元主義側は合意による権限移転、地方官職、旧特権、地方伝承、所領評議、沿岸協力という別々の制度を実際に残さなければ成立せず、単純な善行点では代替できない。

初回比較では帝国が自国の集権だけ、連邦が旧固定外交台帳だけを見ており、「世界」の実在性が不足していた。再修正後は、帝国が生成世界の地方60%以上の実支配、連邦が生成国家との二国間関係から六か国以上の非戦争・関係-10以上を必要とする。

## プレイ中に発見して修正した問題

1. 通常キャリアの月進行が国家改革、集権化キャンペーン、リヴァイアサン周期を進めておらず、国制画面で始めた改革が停止していた。
2. 独立君主でも通常キャリアの主要ナビに「国制」が出ず、世界終局へ到達できなかった。
3. 統治画面の「全国的な中央集権政策」が国制を開かず、汎用国家命令として政績だけを加えていた。
4. バックメニューを開いたまま主要画面へ移ると、透明なメニュー領域が見えている操作を遮った。
5. 横向き844×390では国制ドロワーが379pxに対して831pxまで横にはみ出した。
6. 項目が欠けた旧形式の集権結末では最大障壁に `undefined` が表示された。

## 現時点で残る出来栄え上の問題

1. リヴァイアサン討伐と女神軍迎撃は、現在は国庫・兵力・制度履歴を使う戦略判断であり、専用戦術盤や複数局面の作戦演出ではない。中核概念の判定には十分だが、終盤の手触りは本文中盤の戦役より軽い。
2. 国制画面は国家形成、五改革、歴史政策、災害政策、二終局を一つの長いドロワーへ収めている。横はみ出しは解消したが、終局カードまでの縦移動が長い。
3. 終局条件は開始前に全件を明示する一方、到達までのおおよその月数や、現在の選択がどちらの経路を強めたかを月次報告ではまだ強調しない。
4. 終局後も年代記を続けられる設計にしたため、物語の終止感と継続プレイの利便性が競合する。再開不能にはせず、結末確定後の世界状態を固定して継続する方針を採った。

## 評価

中核の問いである「正しい一つの意思へ委ねる合理性」と「非効率でも人間が決める権利を残す制度」の対立は、ゲーム中の選択履歴と資源条件として成立した。次の品質向上は条件追加ではなく、終局二・三段階目を既存戦役システムへ接続し、同じ思想差を作戦の手触りにも出すことを優先する。
