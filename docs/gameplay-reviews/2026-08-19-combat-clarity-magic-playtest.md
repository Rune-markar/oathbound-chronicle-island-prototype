# 2026-08-19 戦闘明瞭化・魔法実プレイレビュー

## 目的

既存の戦術エンジンが持つ命令、地形、兵站、士気、魔法を減らさず、プレイヤーが「誰に、何を、どこへ指示し、次の判定で何が起こるか」を一画面で理解できるようにする。

## 類似作から採用した原則

- [Into the Breach 公式紹介](https://www.subsetgames.com/itb.html): 敵行動を事前提示し、毎ターン分析して対処する設計を参考に、対象可能マスと発動範囲を予約前後で表示する。
- [Fire Emblem: Shadow Dragon 公式マニュアル](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/nintendo_ds_21/Manual_NintendoDS_FireEmblemShadowDragon_EN.pdf): 攻撃確定前の戦闘予測を参考に、敵への攻撃方法と魔法の対象別数値変化を詳細カードへ表示する。
- [Tactical Breach Wizards 公式ストア説明](https://store.steampowered.com/app/1043810/Tactical_Breach_Wizards/): 固有魔法の組み合わせと自由な試行を参考に、術の役割を名称だけでなく「敵へダメージ」「味方回復」「地形効果」として即読可能にする。
- [Fire Emblem Engage 公式戦闘紹介](https://www.nintendo.com/ph/switch/ayfn/system/battle.html): 味方選択と相性判断を中心にした明快なターン手順を参考に、4段階の固定操作ナビを置く。

本作は同時ターン解決と行動時計を維持するため、他作品のターン構造そのものは模倣せず、事前情報と確認の設計だけを採用した。

## 実装した操作ループ

1. 上部の味方一覧から部隊を選ぶ。
2. 命令、向き、移動、攻撃、または装備魔法を選ぶ。
3. 盤面の有効マスまたは敵を選び、攻撃方法・魔法効果・疲労を確認する。
4. 「命令を実行」で判定を進める。未指示部隊は一覧上で自律と明示する。

魔法は選択した術の射程と対象種別に応じて有効マスを再計算する。射程外と対象不在は予約時点で拒否し、発動時のログだけで失敗を知らせる旧挙動を廃止した。開発戦闘には炎陣、氷縛、治癒、土壁を装備したセレナ魔導隊を入れ、通常の検証入口から魔法を操作できる。

## 反復プレイ結果

- 1回目: 1280×720で新しい手順と味方一覧を確認。標準開発戦闘に魔術兵がいないため、魔法の発見性・検証可能性が不足していると判断した。
- 2回目: 魔導隊を追加し、炎陣選択で術別の有効マス表示を確認。従来の浮動詳細カードが対象マスのクリックを遮る問題を発見した。
- 3回目: 760px以上で詳細カードを右ドック化。炎陣を空き地へ予約し、対象5-6、射程4/6、効果範囲1、疲労+11→11の予告を確認して発動した。戦闘記録に「セレナ魔導隊が炎陣を発動」と記録された。
- 4回目: そのまま第4判定・行動時刻14まで進め、命令一覧、魔法カード、戦闘記録が更新され続けることを確認した。
- 5回目: 844×390へ変更し、操作手順、味方一覧、魔法、実行ボタンがアクセシビリティツリー上に残ることを確認した。日本語グリフはVPSスクリーンショットで欠落したため、表示文字の存在はDOMスナップショットでも照合した。
- 6回目: 同解像度で右ドックの高さが内容量まで伸び、画面下へ切れる問題を発見。戦場行を縮小可能にし、詳細カードを高さ156.9pxの内部スクロールへ収めた。ページ幅・高さのoverflowは0、炎陣の有効対象77マス、予約後プレビュー、コンソールエラー0を再確認した。

## 自動検証範囲

- 魔法の射程外・対象不在拒否、地形魔法の空きマス許可、対象別の非破壊プレビュー。
- 魔法を装備していない場合の使用拒否。
- AI魔術兵が射程外では接近し、射程内で詠唱すること。
- 4段階ナビ、味方一覧、術別対象表示、発動前プレビューのUI契約。
- 機能ブランチでは `npm run check` により構文68ファイルと577/577テストに成功。スマホ可読性の並行変更を保持してmainへ統合後、追加された契約を含む578/578テストにも成功（失敗・スキップ0）。
