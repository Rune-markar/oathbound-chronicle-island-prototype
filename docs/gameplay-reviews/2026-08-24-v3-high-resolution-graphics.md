# 2026-08-24 V3高解像度グラフィック実装レビュー

## 対象と結論

既定入口 `index.html` のGeneration V3を対象に、仮文字、単色タイル、CSSだけの人物形状を実画像へ置換した。ゲーム状態と判定ロジックは変更せず、地形・人物・敵・物品・地点の正本IDを `src/v3-art.js` で画像へ決定論的に対応させる表示層として実装した。

未踏、生成待ち、世界外の3状態は情報を隠すこと自体が仕様であるため、意図的に画像を割り当てていない。それ以外のV3通常導線で出現する仮グラフィックは画像またはベクターへ置換済みである。

## 実装範囲

- 地形: 草地、乾燥草地、砂漠、ツンドラ、雪原、海、海岸、浅瀬、干潟、河川、峡谷河川、運河、泉、オアシス、街道、森林、沼地、田畑、丘陵、山岳、火山、クレーター、洞窟、鉱山、遺跡、浮遊島、空の峰、村・町・都市の地面を高解像度テクスチャへ対応した。
- 地点: 村、町、都市、火山、クレーター、洞窟、鉱山、遺跡、浮遊島、空の峰を透過オブジェクトアートへ対応した。
- 人物・敵: 人間、エルフ、ドワーフ、オークの主人公、旅商人、村人、冒険者、スライム、ゴブリン、狼、山賊、砂サソリ、吸血ヒル、礁蟹、火蜥蜴、幽霊を透過スプライトへ対応した。
- 物品: 薬草、木の実、鉄、銀貨、塩、貝を透過スプライトへ対応した。
- 画面: 起動、新規世界生成、フィールド、遭遇、個人戦、持ち物、軍務、世界地図、世界現象、方向入力の仮記号を画像またはSVGへ置換した。V3から集団戦へ渡す主人公・先陣将・兵站官にも既存の高解像度人物画を設定した。裏社会と交易画面の見出しは既存の高解像度アートを再利用した。
- 地図: 世界地図Canvasの論理解像度768×480は維持し、`devicePixelRatio` に応じて最大1536×960で描画してCSS表示寸法へ縮小する。

アート位置は4×4アトラスの行列として保持し、ラベルは別のDOMテキストとARIA属性へ残した。画像内文字に依存しないため、日本語表示、スクリーンリーダー、画像差し替えを分離できる。

## 配信用アセット

内蔵の画像生成機能を使い、生成元PNGを直接編集せず、配信用コピーだけをWebPへ変換した。

| ファイル | 用途 | 形式・概算容量 |
| --- | --- | --- |
| `assets/generated/v3/field-terrain-atlas.webp` | 地形16枠 | WebP、約600KB |
| `assets/generated/v3/field-object-atlas.webp` | 地点・物品16枠 | 透過WebP、約740KB |
| `assets/generated/v3/field-entity-atlas.webp` | 主人公・NPC・敵16枠 | 透過WebP、約568KB |
| `assets/generated/v3/launch-hero.webp` | 起動・生成画面 | WebP、約244KB |
| `assets/ui/v3-ui-icons.svg` | 機能、方向、戦闘、天候 | SVG symbol sheet |

ラスター4点の合計は約2.1MBである。既存の全身絵・戦場絵・ダンジョン絵を複製せず、利用可能な画面では既存資産を再使用した。

## 最終生成プロンプトセット

生成モードは内蔵 `imagegen`。共通条件は、暗い青緑と古金を基調にした手描きファンタジーRPG、正投影または見下ろし、文字・数字・ロゴ・透かしなし、セル境界を越えないこと、とした。

1. 地形アトラス: 余白・ガターなしの厳密な等分4×4。行順は「緑の草原／乾いた黄金色の草原／淡い砂漠／凍土」「雪原／深海／浅いターコイズ海岸／密林」「沼地／田畑／丘陵／山岳」「火山地／土の街道／河川／石畳」。高解像度のシームレスなゲーム地形テクスチャとして生成する。
2. 地点・物品アトラス: 透明背景の厳密な等分4×4。行順は「村／町／都市／火山」「クレーター／洞窟／鉱山／遺跡」「浮遊島／空の峰／薬草／木の実」「鉄／銀貨／塩／貝」。斜め見下ろしの独立オブジェクトとして生成する。
3. 人物・敵アトラス: 透明背景の厳密な等分4×4。行順は「人間／エルフ／ドワーフ／オークの旅人」「旅商人／村人／巡回冒険者／スライム」「ゴブリン／狼／山賊／砂サソリ」「吸血ヒル／礁蟹／火蜥蜴／幽霊」。全身が枠内に収まるゲームスプライトとして生成する。
4. 起動画: 16:9。生成された大陸を高所から見渡す一人の旅人、遠景に街、街道、森林、山、海、嵐。左上にUIを置ける暗い余白を残し、映画的な手描きキービジュアルとして生成する。

## 回帰と実画面検証

- `npm run check`: ソース94ファイルの構文検査と768テストすべて成功。
- `tests/v3-art.test.mjs`: 配信用画像の存在・最小容量、全地形、全ランドマーク、主人公4種族、NPC、敵、物品、軍勢の対応漏れがないことを確認。
- Chromium 1280×720: 固定シード `v3-graphics-proof` で新規生成し、歩行、旅商人との遭遇、薬草購入、持ち物、世界地図を通常UIで確認。文書横溢れ0、console warning/error各0件。
- Chromium 390×844: 同じ保存から首都まで通常操作で歩き、都市ランドマーク、地形、主人公、上部SVG操作を確認。文書横溢れ0、上部5操作と地図の月送り操作は44px以上、console warning/error各0件。
- 全新規アセットはローカルHTTP経由で200応答。世界地図はDPR 1で768×480、DPR 2の模擬条件で1536×960へ切り替わった。

## 検証境界

自動テストは全IDの対応漏れを検出し、実ブラウザでは代表となる地形、主人公、NPC、商品、都市、世界地図を確認した。敵9種と探索地点10種を一つのプレイ保存で全種類出現させる長時間探索は行っていない。物理端末のGPU、実タッチ操作、実日本語フォントの字形は未検証である。ブラウザ環境に日本語フォントがなかったため、スクリーンショット上の日本語は豆腐表示になったが、DOMとアクセシビリティツリー上のラベルは保持されている。
