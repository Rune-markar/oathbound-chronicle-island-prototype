# V3：発見と成果が見える冒険画面

## 目的

暗い地図と数値窓だけでは、周囲への興味、次の目的、行動の手応えが伝わらない。現在地を見て、発見を選び、自分で近づき、成果を持ち帰る流れを既定のV3へ接続する。

## 画面と遊び方

- PCは地図を中心に、風景・現在の目標・周辺の発見を横へ置く。主人公の状態を地図の外に出し、移動できる地形へ情報窓を重ねない。
- フィールドはPCで15列×9行、幅720px以下で11列×9行（高さ780px以下は11列×7行）。どちらも正方形のマスと主人公中央を保つ。一般の`getV3FieldView`の既定13×11は表示範囲を指定しない呼出し用に残す。
- 新規開始と一歩移動では、半径5マスの円内（通常81マス）を発見済みにする。南北の世界端で打ち切り、東西は循環する。過去の発見は現在のV6保存へ残り、既存セーブは次の移動で視界が広がる。
- 現在地の地形種別から既存の風景画を選ぶ。日時・天候・地勢は実状態から表示する。イラストは地形種別の共通表現であり、生成都市の全建物の再現ではない。
- 周辺案内は発見済み・生成済みの現在の表示範囲だけを対象にする。取得物の用途、敵の勝利報酬とレベル、人物の目的、集落、未完了の見回り地点を表示する。同じ集落を重複掲載しない。
- 通常の案内は同じ種類・名前の最寄りを最大4種まで掲載し、同じ発見の別地点数を示す。「全件を見る」で各地点へ展開できる。地図上の発見数と位置は集約せず、全地点を保つ。
- 案内の項目または離れた既知マスを選ぶと位置を強調する。「東へ一歩」等は、見える範囲の通行可能な経路から次の一歩だけを選び、通常の`movePlayer`へ渡す。途中の敵・人物・危機を経由しない。見える範囲で道がつながらなければ実行できない理由を出す。選択した敵への接近では既存の遭遇判断へ移る。
- 隣接マスの直接クリック、方向キー、方向パッドは既存の一歩操作。現在地の集落・見回り地点を案内から選べば、その地の仕事を開く。地点の選択だけでは時間・位置・資源を変更しない。Escapeで選択解除。
- 地形アトラスは古い草地・街道・集落の背景装飾より優先して描画する。未知マスにはアトラスを割り当てない。
- 旅人、委託、総督、主権国家、結末後で目標と入口を切り替える。集落・見回り地点への移動は目的地を設定した自動モードへ、現地の仕事・政策・外交は同じ人物史へ接続する。
- 所持金・経験・HPの実差分、取得、到着、勝利、成長、地位の変化を行動欄へ表示する。戦闘中は同じ敵の実HP差を使った命中表示を出す。表示から報酬を再適用しない。再読込で過去の獲得演出を再生しない。
- 人物史の見出し、進行段階、選択カード、リヴァイアサン・女神の評議に場面画と強弱を付ける。地位が進んだときは歩みの先頭へ戻して新しい目的を見せる。
- スマートフォンでは短い風景・目標、地図、方向操作、発見一覧の順。長い記録と地勢の根拠は開閉する。自動行動の成果・停止対応は既存の通常導線を維持する。完了後は「報告を閉じる」で表示を片付け、実行設定・進捗・成果は保存したまま待機へ戻す。reduced motionでは移動・点滅・拡大演出を停止する。

## 状態と実装境界

| 内容 | 正本 |
| --- | --- |
| 発見半径 | `src/v3-field-system.js` の `V3_SIGHT_RADIUS` |
| 開発者の作用説明 | `rules.exploration.sightRadius`、`src/v3-variable-catalog.js` |
| 風景・目標・発見・既知経路・成果のモデル | `src/v3-adventure-presentation.js` |
| 選択と描画、実操作への接続 | `src/v3-adventure-ui.js`、`src/v3-app.js` |
| 画面配置と演出 | `index.html`、`v3-adventure.css`、`src/v3-campaign-ui.js` |
| 経路・秘匿・実差分・視界の回帰 | `tests/v3-adventure-presentation.test.mjs`、`tests/v3-field-system.test.mjs` |

選択中の地点、成果演出、表示列数は表示層の一時状態。恒久状態は既存の人物・共通時計・発見・所持品・campaignと現行V6を使用する。経路の外にいる敵を追加したり、選択だけで採集・戦闘・依頼を完了させたりしない。
