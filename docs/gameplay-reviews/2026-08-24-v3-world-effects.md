# V3ワールドエフェクト 実装・実プレイレビュー

## 結論

Generation V3へ、生成済み世界の気候と地勢を根拠に月次変化するワールドエフェクトを接続した。現象は世界地図だけの装飾ではなく、同じ前線状態を詳細フィールドの視覚演出、移動時間、遭遇危険、メッセージ、アクセシブル名へ投影する。月送り、V3専用保存、旧保存の加算移行、共通月次システム、横断イベントへ接続済みである。

## 実装境界

- `src/v3-world-effects.js` が世界シード、年月、概算区画の気温・降水・土壌水分・洪水危険・地理タグから最大9つの前線を決定論的に作る。
- 対象は長雨、暴風雨、降雪、吹雪、砂嵐、熱波、濃霧、降灰。前線は中心、半径、強度、方向、代表地方を持つ。
- 詳細マスでは前線中心からの距離で効果を減衰し、移動時間と遭遇危険へ同じ係数を使う。遠隔の全詳細マスへ状態を保存しない。
- 世界地図の5番目の「現象」レイヤーは現象域を円形グラデーションと境界線で描き、一覧には前線の最大移動補正、現在地欄には距離減衰後の実補正を表示する。
- フィールドは雨、風雪、砂、熱揺らぎ、霧、灰のCSS演出を重ねる。演出層は `pointer-events: none` とし、`prefers-reduced-motion` ではアニメーション時間を最小化する。
- 月境界で `world-effects` システムを一度だけ進め、現在地効果の変化を `world.effect.changed` として保存する。

## 通常UIの実プレイ

検証シードは `world-effects-browser-0`。新しい世界を通常の起動画面から生成し、50年事前史の完了後に確認した。

1. 誓暦317年4月は5現象域が生成され、開始地点は長雨だった。現在地表示は移動 `+18%`、遭遇 `+0.7pt`、雨演出と周辺マスのアクセシブル名はすべて長雨で一致した。
2. 東へ1マス進むと時計は08:00から08:23へ進み、ログは「東へ23分進んだ。密林。長雨の影響を受けている。」となった。表示上の23分と実際の時計差23分が一致した。
3. 世界地図で「現象」を選ぶと、5現象域、地方、強度、半径、最大補正、現象域凡例を表示した。
4. 通常UIの「1か月進める」で誓暦317年5月へ進めると、4現象域へ更新され、現在地は暴風雨、移動 `+7%`、遭遇 `+0.4pt` へ変化した。イベントは `previousEffect: rain`、`currentEffect: storm`、`frontCount: 4` を記録した。
5. 再読込して「冒険を続ける」を選ぶと、年月 `317-5`、4つの前線ID、現在地の暴風雨、1歩、時計43,703分を同じ状態で復元した。

## 画面検証

自動検証は `npm run check` でソース90ファイルの構文検査と737/737テストに成功した。失敗、キャンセル、スキップ、todoは0。世界現象・統合カーネル・動的世界・現状台帳の焦点32/32件も成功した。

### 1280×720

- 文書横溢れ0、世界地図ダイアログ横溢れ0。
- 現象レイヤーの `aria-pressed=true`、凡例表示、現象一覧5件、キャンバス768×480を確認。
- 現地演出は入力を遮らず、長雨の疑似要素は `v3-effect-rain` を実行した。

### 390×844

- 通常画面と世界地図の文書横溢れ0。
- フィールド390×330、方向キーは4方向とも44×44px、地図の5レイヤーボタンは各44px高。
- 世界地図の作業領域は幅370pxで横溢れ0。縦方向は内部スクロールし、世界現象パネル全体を固定フッターの上まで表示できた。
- 暴風雨演出は入力を遮らず、現在地表示、地図、方向キーを同時に利用できた。

### アクセシビリティと実行境界

- 低モーション設定では疑似要素のアニメーション時間が `1e-06s` になった。
- 世界地図はEscapeで閉じ、開いた「世界地図」ボタンへフォーカスを戻す。
- console warning 0件、error 0件。
- 検証ホストに日本語グリフを持つフォントがなく、スクリーンショット上の字形は豆腐表示になった。アクセシビリティツリーの日本語ラベル、配置、寸法、操作、計算は確認したが、実フォントでの字形品質はこの環境では証明していない。

## 次の案

1. **予報と対策を先に入れる。** 宿、港、観測所で翌月の現象候補と信頼度を得て、外套、雪具、覆面、避難所、街道整備で補正を軽減する。現象が単なる不利乱数ではなく、準備して選ぶ旅になる。
2. **災害へ段階発展させる。** 長雨から洪水、熱波から山火事、降灰から噴火警戒へ進み、街道閉鎖、集落在庫、人口、商会販路へ期間付きの結果を残す。不可逆被害には事前警告と退避判断を置く。
3. **幻想現象を希少層として重ねる。** 魔力嵐、星霜、霊霧を遺跡・魔法系統・天体地理と結び、危険だけでなく希少素材、特殊遭遇、地図情報を得る機会にする。

次の優先は「予報と対策」。プレイヤー側の読みと反応を作ってから、経済や人口へ長期被害を広げる方が、理不尽さを避けて既存の1マス歩行を深くできる。
