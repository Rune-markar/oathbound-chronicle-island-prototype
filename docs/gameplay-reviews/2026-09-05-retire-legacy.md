# 旧版起動・保存互換の廃止（2026-09-05）

## 変更と理由

ユーザーの「旧バージョンとの互換性は削除しても良い。ゲーム画面からも消すこと」に合わせ、V3の新規開始・再開を唯一のゲーム入口とした。

- `legacy-v2.html` の公開入口と起動リンクを削除。旧版はGit履歴で参照する。
- V3軍務が利用する編成・兵站・戦術盤・戦果を `group-battle.html` と `src/group-battle-entry.js` へ分離。有効なpending引渡しがない場合は `index.html` へ戻る。
- 共有戦闘計算と描画関数を維持し、非戦闘DOMは非表示・inertにした。旧版の人物セーブ読込・書込、起動画面・戦略地図の初期描画は停止した。
- 保存全体V6とシステム別現行版を厳密照合し、旧版・未来版・版台帳不足を拒否する。旧保存の時計・世界情勢・種族状態の段階移行を削除。読込失敗で元の保存を書き換えない。
- 並行作業の市場経済main `2ba2a0d` を取り込み、world-simulation v4と持越在庫を維持した。
- 集団戦編成のスマホ表示で行が圧縮されて重なったため、専用CSSで各行の内容高を確保した。

- Node.js 22.23.2: `npm run check`、src 98ファイル構文確認、788/788テスト成功、失敗・skipなし。
- `npm run remote:check` と `git diff --check` 成功。
- 現行セーブ往復、旧全体版・旧システム版・将来版・欠落台帳の拒否、拒否時の保存不変を回帰確認した。
- headless Chromium、1280×720と390×844、通常入口 `index.html`、シード `v3-retire-legacy-browser`、192×120・7国家・50年事前史を使用。
- 新規生成、軍務受諾、西へ7歩、集団戦準備、編成中止、同じ座標57,520・7歩への帰還とブリッジ消去を確認した。
- 集団戦専用画面の旧メニュー表示なし、旧版保存キーの生成なし、横溢れ0。スマホ編成の人物欄下端と配置欄上端が一致し、配置欄下端と兵站欄上端も一致した。

- 第55ターンに勝利し、戦果画面の通常ボタンからV3へ帰還。座標57,520、銀貨27、経験20、軍功12、軍務履歴1件、activeMissionなし、一時ブリッジなしを確認。再読込して「冒険を続ける」から再開しても値は一致し、二重報酬は発生しなかった。
- ブラウザ内の検証用コピーを保存全体V5にして再読込すると、再開ボタンが無効になり、旧保存の内容と旧V2保存キーの検証用文字列は変わらなかった。現行コピーを戻すと再開できた。
- `group-battle.html?v3-group-battle=stale-request` はV3起動画面へ戻り、`legacy-v2.html` はHTTP 404。ゲーム画面の旧版リンクなし。
- 最終console error・warning 0、PC・スマホとも横溢れ0。確認用ブラウザとlocalhostサーバーは終了済み。

## 境界

共有ドメインと集団戦に必要な既存描画資産は残す。旧世代の設計記録・単体ドメイン回帰は歴史的資料として残し、現行ゲームから旧版を起動する根拠にしない。ブラウザ証跡はheadless Chromiumであり物理端末実機ではない。push・公開・deployは実施しない。
