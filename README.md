# 誓界記 — 小島嶼グランドストラテジー

セレナ島侯国を国家・三都市・六村の三つの縮尺で扱う、ブラウザ向け戦略ゲーム試作です。食料の数量目標ではなく、海峡の通航税、商船拿捕、港湾規則の不一致、軍情報の食い違いといった具体的な事象から国家運営を始めます。

- 非公開リポジトリ: <https://github.com/Rune-markar/oathbound-chronicle-island-prototype>
- 更新履歴: <https://github.com/Rune-markar/oathbound-chronicle-island-prototype/blob/main/CHANGELOG.md>

## 実装範囲

- EU4系グランドストラテジーを参照した、上部資源バー・左側国家画面・中央地図・右側アウトライナー
- 政治・外交・補給・不穏の地図モードと、国家・都市圏・村々の表示縮尺
- 1国家、3都市、6村、海峡を挟む隣国、中立港
- 費用と日数を持つ行政・外交・軍事・人材コマンド
- Notion原案の「仕官」「勧誘」「登用」、協定打診、経済支援、開戦正当性
- 「自由通航」「共同管理」「政権屈服」から政治目的を先に選ぶ宣戦布告
- 戦力比だけでなく、正当性、海上交通、海峡、補給、情報確度、介入リスク、攻勢限界を説明する戦争AI
- 商路封鎖・海峡確保・限定上陸の作戦方針、週次戦況、講和
- ローカル保存と継続する年代記

## 起動

ES Modulesを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

```powershell
python -m http.server 4180
```

ブラウザで `http://127.0.0.1:4180/` を開いてください。

## 検証

```powershell
npm run check
```

国家進行は `src/simulation.js`、戦争判断は `src/war-ai.js`、画面制御は `src/app.js` に分けています。外部ライブラリ、外部画像、外部通信は使用しません。
